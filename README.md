## 使用方式

- 每个目录下的 `README.md` 是**题目 + 答案/解析**，可直接阅读。
- 目录下的 `.js` / `.html` 是**可运行示例**：
  - JS 文件：`node xxx.js` 直接运行（如 `node 控制并发/index.js`）。
  - HTML 文件：用浏览器打开即可预览效果（如 `lazyLoad/lazy/index.html`）。

## 贡献约定

- 一个考点一个目录，`README.md` 说明「题目、思路、代码、易错点」。
- 代码示例保持 **自包含、可运行、带注释**。
- 多种解法尽量都保留，并对比优劣。
