## 1. 动态规划解题四步法

**题目：** 以「最小花费爬楼梯」为例，说明动态规划的四步法。数组 `cost[i]` 表示从第 `i` 阶向上爬需要支付的费用，可以从下标 0 或 1 出发，每次爬一阶或两阶，求到达楼顶的最小花费。示例：

```js
minCostClimbingStairs([10, 15, 20]); // 15，从第 1 阶出发直接到顶
minCostClimbingStairs([1, 100, 1, 1, 1, 100, 1, 1, 100, 1]); // 6
```

**思路：** 四步法的顺序是：定义状态、写转移方程、确定初始化、确定遍历顺序与返回值。本题定义 `dp[i]` 为「到达第 `i` 阶的最小花费」，楼顶是第 `n` 阶；转移为 `dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`；初始化 `dp[0] = dp[1] = 0`，因为站在起点不花钱；按 `i` 从小到大遍历，返回 `dp[n]`。暴力递归会重复计算子问题，指数级；加备忘录降到 O(n)；再用滚动变量把空间压到 O(1)。

**代码：**

```js
// 暴力：每个位置两种走法，O(2^n)
function minCostBrute(cost, i = cost.length) {
    if (i <= 1) return 0;
    return Math.min(
        minCostBrute(cost, i - 1) + cost[i - 1],
        minCostBrute(cost, i - 2) + cost[i - 2]
    );
}

// 记忆化搜索：自顶向下，O(n)
function minCostMemo(cost) {
    const memo = new Array(cost.length + 1).fill(-1);
    function dp(i) {
        if (i <= 1) return 0;
        if (memo[i] !== -1) return memo[i];
        memo[i] = Math.min(dp(i - 1) + cost[i - 1], dp(i - 2) + cost[i - 2]);
        return memo[i];
    }
    return dp(cost.length);
}

// 递推 + 滚动变量：O(n) 时间，O(1) 空间
function minCostClimbingStairs(cost) {
    let prev = 0;
    let cur = 0;
    for (let i = 2; i <= cost.length; i++) {
        const next = Math.min(cur + cost[i - 1], prev + cost[i - 2]);
        prev = cur;
        cur = next;
    }
    return cur;
}
```

**四步法检查清单：**

| 步骤 | 要回答的问题 | 常见错误 |
| --- | --- | --- |
| 状态定义 | `dp[i]` 表示什么，维度是否足够 | 语义含糊，写不出转移 |
| 转移方程 | 最后一个决策是什么 | 漏掉某种决策 |
| 初始化 | 最小子问题的答案是什么 | 依赖非法下标 |
| 遍历顺序 | 依赖项是否已经算出 | 区间 DP 方向写反 |

**复杂度：** 暴力 O(2^n)；记忆化与递推 O(n)；滚动变量后空间 O(1)。

**边界与坑：**

- 状态定义要包含「到达」还是「离开」的语义，差一步就会多算或漏算费用。
- 初始化要符合定义：站在 0、1 阶不花钱，所以两者都是 0。
- 遍历顺序必须保证依赖项先算出来，本题是从小到大。
- 返回的是楼顶 `n`，不是最后一个台阶 `n-1`。

**面试怎么答：** 按四步法逐条说，先给定义与方程，再讲初始化和遍历顺序，最后分析复杂度。主动补充「暴力 → 记忆化 → 递推 → 滚动数组」的优化路径，并说明记忆化搜索与递推的取舍：前者好写、只算必要状态，后者无递归开销。

**易错点：**

- `dp[i]` 定义成「从 i 出发的最小花费」，转移方向就要反过来，混用会错。
- 初始化写成 `dp[0] = cost[0]`，把起点的费用重复计算。
- 循环从 0 开始访问 `cost[-1]`。
- 只写递推不解释状态含义，面试官无法判断是否真正理解。

## 2. 爬楼梯与打家劫舍

**题目：** 爬楼梯：每次可以爬 1 或 2 阶，求爬到第 `n` 阶的方法数。打家劫舍：不能偷相邻的两家，求最大金额；进阶版本首尾相连成环。示例：

```js
climbStairs(3); // 3：1+1+1、1+2、2+1
rob([2, 7, 9, 3, 1]); // 12：偷 2、9、1
robCircle([2, 3, 2]); // 3：首尾不能同时偷
```

**思路：** 爬楼梯是斐波那契：`dp[i] = dp[i-1] + dp[i-2]`，因为最后一步要么跨一阶、要么跨两阶。打家劫舍是「选或不选」：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，分别对应不偷当前家和偷当前家。两者都只用前两个状态，所以用两个变量滚动即可。环形版本拆成两种情况：不偷第一家、不偷最后一家，分别求线性最大值再取较大者。

**代码：**

```js
function climbStairs(n) {
    if (n <= 2) return n;
    let prev = 1;
    let cur = 2;
    for (let i = 3; i <= n; i++) {
        const next = prev + cur;
        prev = cur;
        cur = next;
    }
    return cur;
}

function robRange(nums, left, right) {
    let prev = 0;
    let cur = 0;
    for (let i = left; i <= right; i++) {
        const next = Math.max(cur, prev + nums[i]);
        prev = cur;
        cur = next;
    }
    return cur;
}

function rob(nums) {
    return robRange(nums, 0, nums.length - 1);
}

function robCircle(nums) {
    if (nums.length === 1) return nums[0];
    return Math.max(
        robRange(nums, 0, nums.length - 2),
        robRange(nums, 1, nums.length - 1)
    );
}
// 树形打家劫舍：返回 [偷当前节点, 不偷当前节点] 的最大值
function robTree(root) {
    function dfs(node) {
        if (!node) return [0, 0];
        const [robLeft, skipLeft] = dfs(node.left);
        const [robRight, skipRight] = dfs(node.right);
        const robCur = node.val + skipLeft + skipRight;
        const skipCur = Math.max(robLeft, skipLeft) + Math.max(robRight, skipRight);
        return [robCur, skipCur];
    }
    const [rob, skip] = dfs(root);
    return Math.max(rob, skip);
}
```

**复杂度：** 时间 O(n)，每个位置计算一次；空间 O(1)，只保留前两个状态。

**边界与坑：**

- `n = 1` 时爬楼梯返回 1，`n = 2` 返回 2，初始化要单独处理。
- 打家劫舍空数组返回 0；环形版本长度为 1 时直接返回该元素。
- 环形拆分的两个区间是 `[0, n-2]` 与 `[1, n-1]`，不能两个都包含首尾。
- 金额可能很大，JS 中超过 `Number.MAX_SAFE_INTEGER` 需要用 `BigInt`。

**面试怎么答：** 先说爬楼梯的本质是斐波那契，给出转移与滚动优化。打家劫舍强调「每个位置只有偷与不偷两个决策」，这是最基础的选或不选模型。环形版本说明「首尾互斥」的拆分技巧，并指出拆分后仍是两个线性子问题。

**易错点：**

- 爬楼梯循环从 1 开始，导致重复初始化。
- 打家劫舍转移写成 `max(dp[i-1], dp[i-2]) + nums[i]`，语义错误。
- 环形版本忘记处理长度为 1 的数组。
- 用递归不加重套缓存，输入较大时超时。

## 3. 背包问题（01 背包 / 完全背包）

**题目：** 给定物品重量 `weights`、价值 `values` 和背包容量 `capacity`，求能装下的最大价值。01 背包每个物品只能用一次；完全背包每个物品可以用无限次。示例：

```js
knapsack01([1, 2, 3], [6, 10, 12], 5);       // 22，选重量 2 + 3
knapsackComplete([1, 2, 3], [6, 10, 12], 5); // 30，选 5 个重量 1
```

**思路：** 二维状态 `dp[i][c]` 表示前 `i` 个物品、容量 `c` 的最大价值。01 背包的转移是 `dp[i][c] = max(dp[i-1][c], dp[i-1][c-w] + v)`，第二项来自上一行，保证每个物品只选一次。压成一维后，容量必须从大到小遍历，否则同一物品会被重复使用。完全背包允许重复选，转移第二项来自本行 `dp[i][c-w]`，压成一维后容量从小到大遍历，正好让物品可以再次被选。

**代码：**

```js
function knapsack01(weights, values, capacity) {
    const dp = new Array(capacity + 1).fill(0);
    for (let i = 0; i < weights.length; i++) {
        for (let c = capacity; c >= weights[i]; c--) {
            dp[c] = Math.max(dp[c], dp[c - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}

// 二维写法，便于看清「上一行」的来源
function knapsack01Table(weights, values, capacity) {
    const n = weights.length;
    const dp = Array.from({ length: n + 1 }, () => new Array(capacity + 1).fill(0));
    for (let i = 1; i <= n; i++) {
        for (let c = 0; c <= capacity; c++) {
            dp[i][c] = dp[i - 1][c];
            if (c >= weights[i - 1]) {
                dp[i][c] = Math.max(
                    dp[i][c],
                    dp[i - 1][c - weights[i - 1]] + values[i - 1]
                );
            }
        }
    }
    return dp[n][capacity];
}

function knapsackComplete(weights, values, capacity) {
    const dp = new Array(capacity + 1).fill(0);
    for (let i = 0; i < weights.length; i++) {
        for (let c = weights[i]; c <= capacity; c++) {
            dp[c] = Math.max(dp[c], dp[c - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}
```

**复杂度：** 时间 O(nC)，物品数乘容量；空间 O(C)，一维数组。二维写法空间 O(nC)。

**边界与坑：**

- 容量为 0 时返回 0；物品重量超过容量时内层循环不会执行。
- 01 背包一维写法必须倒序，正序会变成「每个物品无限次」。
- 完全背包一维写法必须正序，倒序会退化成 01 背包。
- 「恰好装满」与「至多装满」的初始化不同：前者 `dp[0]=0`、其余 `-Infinity`，后者全部为 0。
- 求方案数时，外层物品、内层容量得到组合数；交换循环得到排列数。

**面试怎么答：** 先写二维转移，讲清 `dp[i-1]` 与 `dp[i]` 的来源差异，再演示一维压缩。重点解释「01 倒序、完全正序」的原因：倒序保证当前物品只用一次，正序允许复用。被问方案数时，补充循环顺序对组合与排列的影响。

**易错点：**

- 01 背包写成正序，同一个物品被反复加入。
- 完全背包写成倒序，退化成 01 背包。
- 内层循环边界写成 `c > weights[i]`，漏掉恰好装满的情况。
- 把「最大价值」与「方案数」的转移混用，前者取 max、后者求和。

## 4. 最长递增子序列

**题目：** 给定整数数组，求最长严格递增子序列的长度。子序列不要求连续，但相对顺序不能改变。示例：

```js
lengthOfLIS([10, 9, 2, 5, 3, 7, 101, 18]); // 4，如 2, 3, 7, 101
lengthOfLIS([0, 1, 0, 3, 2, 3]);           // 4，如 0, 1, 2, 3
```

**思路：** 暴力枚举所有子序列是指数级。DP 做法定义 `dp[i]` 为「以 `nums[i]` 结尾的最长递增子序列长度」，转移枚举所有 `j < i` 且 `nums[j] < nums[i]`，取 `dp[j] + 1` 的最大值，时间 O(n²)。最优做法是维护数组 `tails`，其中 `tails[k]` 表示长度为 `k+1` 的递增子序列的最小结尾值；遍历每个数，用二分找到第一个大于等于它的位置并替换，长度增加时追加。`tails` 本身不是某个合法子序列，但长度就是答案，时间 O(n log n)。

**代码：**

```js
function lengthOfLISQuadratic(nums) {
    const dp = new Array(nums.length).fill(1);
    let ans = 0;
    for (let i = 0; i < nums.length; i++) {
        for (let j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        ans = Math.max(ans, dp[i]);
    }
    return ans;
}

function lengthOfLIS(nums) {
    const tails = [];
    for (const x of nums) {
        let lo = 0;
        let hi = tails.length;
        while (lo < hi) {
            const mid = (lo + hi) >> 1;
            if (tails[mid] < x) {
                lo = mid + 1;
            } else {
                hi = mid;
            }
        }
        tails[lo] = x;
    }
    return tails.length;
}
// 还原一条具体的最长递增子序列
function lisWithPath(nums) {
    const dp = new Array(nums.length).fill(1);
    const prev = new Array(nums.length).fill(-1);
    let best = 0;
    for (let i = 0; i < nums.length; i++) {
        for (let j = 0; j < i; j++) {
            if (nums[j] < nums[i] && dp[j] + 1 > dp[i]) {
                dp[i] = dp[j] + 1;
                prev[i] = j;
            }
        }
        if (dp[i] > dp[best]) best = i;
    }
    const path = [];
    for (let cur = best; cur !== -1; cur = prev[cur]) {
        path.push(nums[cur]);
    }
    return path.reverse();
}
```

**复杂度：**

| 做法 | 时间 | 空间 | 说明 |
| --- | --- | --- | --- |
| 动态规划 | O(n²) | O(n) | 好写，能还原具体子序列 |
| 贪心 + 二分 | O(n log n) | O(n) | 只求长度，`tails` 不是答案序列 |

**边界与坑：**

- 空数组返回 0。
- 严格递增用 `lower_bound`（第一个大于等于 `x` 的位置），非递减要用 `upper_bound`。
- `tails` 数组只是「各长度的最小结尾」，不能直接当成最长递增子序列输出。
- 需要还原具体序列时，额外记录每个元素的前驱下标。

**面试怎么答：** 先给 O(n²) 的 DP，状态定义说清「以 i 结尾」，这是能还原路径的写法。再给 O(n log n) 的贪心加二分，重点解释 `tails[k]` 的含义与「替换更小结尾不会变差」的直觉。被追问还原序列时，答记录前驱或记录每个元素进入 `tails` 时的长度。

**易错点：**

- 二分条件写成 `<=`，把严格递增变成非递减。
- 把 `tails` 直接返回，得到的是最小结尾数组而不是子序列。
- DP 初始化忘记每个元素自身长度为 1。
- 只比较相邻元素，误把「连续递增」当成「递增子序列」。

## 5. 编辑距离

**题目：** 给定两个字符串 `word1`、`word2`，返回把 `word1` 变成 `word2` 的最少操作数。允许插入、删除、替换一个字符。示例：

```js
editDistance('horse', 'ros');   // 3
editDistance('intention', 'execution'); // 5
```

**思路：** 暴力的递归会重复计算大量子问题，是指数级。定义 `dp[i][j]` 为「`word1` 前 `i` 个字符变成 `word2` 前 `j` 个字符的最少操作数」。边界：`dp[i][0] = i`（全删），`dp[0][j] = j`（全插）。转移：若末尾字符相同，`dp[i][j] = dp[i-1][j-1]`；否则取三种操作的最小值加一：删除 `dp[i-1][j]`、插入 `dp[i][j-1]`、替换 `dp[i-1][j-1]`。时间 O(mn)，空间可压缩到 O(min(m, n))。

**代码：**

```js
function editDistance(word1, word2) {
    const m = word1.length;
    const n = word2.length;
    const dp = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));
    for (let i = 0; i <= m; i++) dp[i][0] = i;
    for (let j = 0; j <= n; j++) dp[0][j] = j;
    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            if (word1[i - 1] === word2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = 1 + Math.min(
                    dp[i - 1][j],
                    dp[i][j - 1],
                    dp[i - 1][j - 1]
                );
            }
        }
    }
    return dp[m][n];
}

// 滚动数组：只保留上一行
function editDistanceOptimized(word1, word2) {
    if (word1.length < word2.length) {
        return editDistanceOptimized(word2, word1);
    }
    const n = word2.length;
    let prev = Array.from({ length: n + 1 }, (_, j) => j);
    for (let i = 1; i <= word1.length; i++) {
        const cur = new Array(n + 1).fill(0);
        cur[0] = i;
        for (let j = 1; j <= n; j++) {
            if (word1[i - 1] === word2[j - 1]) {
                cur[j] = prev[j - 1];
            } else {
                cur[j] = 1 + Math.min(prev[j], cur[j - 1], prev[j - 1]);
            }
        }
        prev = cur;
    }
    return prev[n];
}
```

**复杂度：** 时间 O(mn)；二维空间 O(mn)，滚动数组 O(min(m, n))。

**边界与坑：**

- 两个空串返回 0；一个空串返回另一个的长度。
- 下标从 1 开始，访问字符要写 `word1[i-1]`。
- 三种操作的下标对应关系容易记反：删除看上一行、插入看左一格、替换看左上角。
- 含 emoji 等代理对字符时，`length` 按 UTF-16 码元计数，需要先 `Array.from` 拆成字符。

**面试怎么答：** 先说状态定义与三种操作的来源，把 `dp[i-1][j]`、`dp[i][j-1]`、`dp[i-1][j-1]` 分别对应删除、插入、替换。再写二维表并说明初始化。被问空间优化时，答「每一行只依赖上一行和当前行左侧」，所以可以滚动。

**易错点：**

- 字符相同时仍然加一，导致结果偏大。
- 初始化漏掉 `dp[0][j]` 或 `dp[i][0]`。
- 三种操作取最小值时把 `dp[i][j-1]` 写成 `dp[i-1][j-1]`。
- 滚动数组更新 `prev` 的时机写错，把当前行覆盖后再使用。

## 6. 股票买卖系列

**题目：** 给定每日股价，分别求：只能买卖一次的最大利润；可以买卖无限次的最大利润；最多买卖两次的最大利润。同一时刻最多持有一股，卖出后才能再买。示例：

```js
maxProfitOnce([7, 1, 5, 3, 6, 4]);       // 5，1 买 6 卖
maxProfitUnlimited([1, 2, 3, 4, 5]);     // 4，每天都低买高卖
maxProfitTwo([3, 3, 5, 0, 0, 3, 1, 4]);  // 6，两笔交易
```

**思路：** 一次交易只需维护「历史最低价」，每天用当前价减最低价更新答案。无限次交易把问题拆成相邻两天的差，只要明天涨就今天买、明天卖，所有正差值之和就是答案。两次交易用四个状态：`buy1`、`sell1`、`buy2`、`sell2`，分别表示第一次持有、第一次卖出、第二次持有、第二次卖出后的最大收益，每天按顺序更新。更一般的 `k` 次交易用二维 DP，冷冻期与手续费只是在状态转移上加条件。

**代码：**

```js
function maxProfitOnce(prices) {
    let minPrice = Infinity;
    let ans = 0;
    for (const price of prices) {
        ans = Math.max(ans, price - minPrice);
        minPrice = Math.min(minPrice, price);
    }
    return ans;
}

function maxProfitUnlimited(prices) {
    let ans = 0;
    for (let i = 1; i < prices.length; i++) {
        if (prices[i] > prices[i - 1]) {
            ans += prices[i] - prices[i - 1];
        }
    }
    return ans;
}

function maxProfitTwo(prices) {
    let buy1 = -Infinity;
    let sell1 = 0;
    let buy2 = -Infinity;
    let sell2 = 0;
    for (const price of prices) {
        buy1 = Math.max(buy1, -price);
        sell1 = Math.max(sell1, buy1 + price);
        buy2 = Math.max(buy2, sell1 - price);
        sell2 = Math.max(sell2, buy2 + price);
    }
    return sell2;
}
```

**复杂度：** 三种做法都是时间 O(n)、空间 O(1)。`k` 次交易的时间 O(kn)、空间 O(k)。

**边界与坑：**

- 价格为空或只有一天时利润为 0，`buy` 状态初始化为 `-Infinity`。
- 同一天不能既买又卖，但无限次交易的差值法在数学上等价，结果正确。
- 两次交易的四个状态必须按 `buy1 → sell1 → buy2 → sell2` 的顺序更新，顺序反了会用到当天刚更新的值。
- 冷冻期要求卖出后隔一天才能买，转移要引用 `i-2`；手续费在卖出时扣减。

**面试怎么答：** 先说「一次交易是前缀最小值」，再说「无限次是所有正差值之和」。两次交易用状态机解释四个变量的含义，强调它们表示「手上有股票或空仓」的最大收益。被问 `k` 次、冷冻期、手续费时，答统一用「第 i 天、第 j 次交易、是否持仓」的 DP。

**易错点：**

- 一次交易先更新最低价再算利润，遇到当天就卖的逻辑会得到 0。
- 无限次交易写成 `max(0, prices[i] - prices[i-2])`，把简单问题复杂化。
- 两次交易只遍历一次却试图同时记录两笔，状态顺序写反。
- 把 `buy` 初始化成 0，导致「买入」被当成免费，利润虚高。

## 7. 区间 DP（最长回文子序列）

**题目：** 给定字符串 `s`，求最长回文子序列的长度。子序列不要求连续，但相对顺序不能改变。示例：

```js
longestPalindromeSubseq('bbbab'); // 4，'bbbb'
longestPalindromeSubseq('cbbd');  // 2，'bb'
```

**思路：** 区间 DP 的状态定义在「区间」上，而不是前缀。`dp[i][j]` 表示 `s[i..j]` 的最长回文子序列长度。若 `s[i] === s[j]`，两端都能用上，`dp[i][j] = dp[i+1][j-1] + 2`；否则至少舍弃一端，`dp[i][j] = max(dp[i+1][j], dp[i][j-1])`。初始化 `dp[i][i] = 1`，空区间视为 0。遍历顺序必须保证 `i+1` 与 `j-1` 先算出，所以 `i` 从大到小、`j` 从小到大。

**代码：**

```js
function longestPalindromeSubseq(s) {
    const n = s.length;
    if (n === 0) return 0;
    const dp = Array.from({ length: n }, () => new Array(n).fill(0));
    for (let i = n - 1; i >= 0; i--) {
        dp[i][i] = 1;
        for (let j = i + 1; j < n; j++) {
            if (s[i] === s[j]) {
                dp[i][j] = dp[i + 1][j - 1] + 2;
            } else {
                dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[0][n - 1];
}

// 滚动数组：只保留 i+1 行
function longestPalindromeSubseqRolling(s) {
    const n = s.length;
    if (n === 0) return 0;
    let prev = new Array(n).fill(0);
    for (let i = n - 1; i >= 0; i--) {
        const cur = new Array(n).fill(0);
        cur[i] = 1;
        for (let j = i + 1; j < n; j++) {
            if (s[i] === s[j]) {
                cur[j] = prev[j - 1] + 2;
            } else {
                cur[j] = Math.max(prev[j], cur[j - 1]);
            }
        }
        prev = cur;
    }
    return prev[n - 1];
}
// 最长回文子串：中心扩展，时间 O(n²)、空间 O(1)
function longestPalindrome(s) {
    let start = 0;
    let maxLen = 1;
    function expand(left, right) {
        while (left >= 0 && right < s.length && s[left] === s[right]) {
            left--;
            right++;
        }
        const len = right - left - 1;
        if (len > maxLen) {
            maxLen = len;
            start = left + 1;
        }
    }
    for (let i = 0; i < s.length; i++) {
        expand(i, i);
        expand(i, i + 1);
    }
    return s.slice(start, start + maxLen);
}
```

**复杂度：** 时间 O(n²)，区间总数约为 n²/2；空间 O(n²)，滚动数组可降到 O(n)。

**边界与坑：**

- 单字符返回 1，空串返回 0。
- `i + 1 > j - 1` 时 `dp[i+1][j-1]` 应视为 0，二维数组默认值正好满足。
- 遍历顺序写反会读到未计算的状态，得到错误答案。
- 最长回文「子串」要求连续，做法是中心扩展或 Manacher，不能套用本题的转移。

**面试怎么答：** 先讲「区间 DP 的状态依赖更短的区间」，再给转移与遍历顺序。可以画一张二维表说明 `i` 倒序、`j` 正序的原因。被追问空间优化时，答每一行只依赖下一行与当前行左侧，所以两个一维数组即可。

**易错点：**

- `i` 从小到大遍历，`dp[i+1]` 还没算。
- 字符相等时忘记加 2，或者只加 1。
- 把子序列当成子串，要求字符连续。
- 空串访问 `dp[0][-1]`，需要单独返回。

## 8. 回溯模板与全排列、子集

**题目：** 实现全排列与子集。全排列返回数组元素的所有排列；子集返回数组的所有子集（幂集）。示例：

```js
permute([1, 2, 3]); // 6 个排列
subsets([1, 2, 3]); // 8 个子集，含空集
```

**思路：** 回溯的本质是遍历决策树，模板是「做选择 → 递归 → 撤销选择」。全排列在每一步选择一个尚未使用的元素，用 `used` 数组记录，路径长度等于数组长度时收集结果。子集在每个节点都收集当前路径，然后用 `start` 参数保证只向后选，避免同一组合以不同顺序重复出现。排列的复杂度是 O(n·n!)，子集是 O(n·2^n)，递归深度都是 O(n)。

**代码：**

```js
function permute(nums) {
    const res = [];
    const path = [];
    const used = new Array(nums.length).fill(false);
    function backtrack() {
        if (path.length === nums.length) {
            res.push([...path]);
            return;
        }
        for (let i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            used[i] = true;
            path.push(nums[i]);
            backtrack();
            path.pop();
            used[i] = false;
        }
    }
    backtrack();
    return res;
}

function subsets(nums) {
    const res = [];
    const path = [];
    function backtrack(start) {
        res.push([...path]);
        for (let i = start; i < nums.length; i++) {
            path.push(nums[i]);
            backtrack(i + 1);
            path.pop();
        }
    }
    backtrack(0);
    return res;
}
// 有重复元素的全排列：排序后跳过错层重复
function permuteUnique(nums) {
    const res = [];
    const path = [];
    const used = new Array(nums.length).fill(false);
    nums.sort((a, b) => a - b);
    function backtrack() {
        if (path.length === nums.length) {
            res.push([...path]);
            return;
        }
        for (let i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            if (i > 0 && nums[i] === nums[i - 1] && !used[i - 1]) continue;
            used[i] = true;
            path.push(nums[i]);
            backtrack();
            path.pop();
            used[i] = false;
        }
    }
    backtrack();
    return res;
}
```

**复杂度：** 全排列时间 O(n·n!)，子集时间 O(n·2^n)；空间 O(n)，为递归栈与路径，结果本身不计入。

**边界与坑：**

- 空数组：全排列返回 `[[]]`，子集也返回 `[[]]`。
- 收集结果时必须拷贝 `path`，直接 `push(path)` 会在回溯后被清空。
- 有重复元素时需要先排序，再用 `i > start && nums[i] === nums[i-1]` 跳过同层重复。
- 子集不要用 `used`，用 `start` 才能保证组合不重复。

**面试怎么答：** 先背模板：路径、选择列表、结束条件、做选择、递归、撤销。全排列讲「顺序有关，用 used 禁止重复选同一个下标」；子集讲「每个节点都是答案，用 start 保证只向后选」。被问重复元素时，答排序加同层去重，并说明为什么不能跨层去重。

**易错点：**

- 结果收集时没有深拷贝，所有结果指向同一个数组。
- 全排列忘记撤销 `used[i] = false`，后续分支缺少元素。
- 子集用 `used` 而不是 `start`，产生大量重复排列。
- 去重条件写成 `nums[i] === nums[i-1]`，把不同层的合法重复也剪掉。

## 9. 组合总和与剪枝

**题目：** 给定无重复正整数数组 `candidates` 和目标值 `target`，找出所有和为 `target` 的组合，同一个数可以无限次选取。进阶：数组可能有重复元素，每个数只能用一次，结果不能有重复组合。示例：

```js
combinationSum([2, 3, 6, 7], 7); // [[2, 2, 3], [7]]
combinationSum2([10, 1, 2, 7, 6, 1, 5], 8); // [[1, 1, 6], [1, 2, 5], [1, 7], [2, 6]]
```

**思路：** 仍是回溯模板，但有两个关键点。第一，用 `start` 保证组合内部有序，避免 `[2,3]` 与 `[3,2]` 重复。第二，先排序，递归时若当前元素已经大于剩余目标，后面的元素更大，可以直接 `break`，这是最有效的剪枝。允许重复选时递归传 `i`，不允许时传 `i+1`。有重复元素时，同一层跳过相同值，避免重复组合。

**代码：**

```js
function combinationSum(candidates, target) {
    const res = [];
    const path = [];
    candidates.sort((a, b) => a - b);
    function backtrack(start, rest) {
        if (rest === 0) {
            res.push([...path]);
            return;
        }
        for (let i = start; i < candidates.length; i++) {
            if (candidates[i] > rest) break;
            path.push(candidates[i]);
            backtrack(i, rest - candidates[i]);
            path.pop();
        }
    }
    backtrack(0, target);
    return res;
}

function combinationSum2(candidates, target) {
    const res = [];
    const path = [];
    candidates.sort((a, b) => a - b);
    function backtrack(start, rest) {
        if (rest === 0) {
            res.push([...path]);
            return;
        }
        for (let i = start; i < candidates.length; i++) {
            if (candidates[i] > rest) break;
            if (i > start && candidates[i] === candidates[i - 1]) continue;
            path.push(candidates[i]);
            backtrack(i + 1, rest - candidates[i]);
            path.pop();
        }
    }
    backtrack(0, target);
    return res;
}
```

**复杂度：** 最坏为指数级，与目标值和候选值有关；递归深度不超过 `target / min(candidates)`，空间 O(深度)。

**边界与坑：**

- 候选数为正，`rest` 只会减小；若允许 0，需要防止无限递归。
- 排序是剪枝与去重的前提，不排序只能做较弱的判断。
- `break` 与 `continue` 的差别：大于剩余目标用 `break`，同层重复用 `continue`。
- 允许重复选传 `i`，只选一次传 `i + 1`，写反会漏解或重复。

**面试怎么答：** 先写不带剪枝的版本，再补排序与 `break`，说明剪枝为什么安全。强调 `start` 控制组合顺序、`i` 与 `i+1` 控制元素复用。被问重复元素时，答「同一层相同值只取第一个」，并解释跨层可以重复是因为它们属于不同选择。

**易错点：**

- 用 `i > 0` 而不是 `i > start` 去重，误删不同层的合法解。
- 剪枝用 `continue`，后面的元素仍被遍历，效率低。
- 允许重复选时传 `i + 1`，漏掉同一元素的多次使用。
- 结果没有拷贝路径，最终全部为空数组。

## 10. N 皇后与解数独

**题目：** N 皇后：在 `n × n` 棋盘放 `n` 个皇后，任意两个不能同行、同列、同对角线，返回所有方案。解数独：填充 `9 × 9` 棋盘中的空格，使每行、每列、每个 `3 × 3` 宫都包含 1 到 9。示例：

```js
solveNQueens(4); // 2 种方案
solveSudoku(board); // 原地修改 board
```

**思路：** N 皇后按行放置，每行只放一个，因此只需检查列与两条对角线。用三个集合记录已占用的列、主对角线 `row - col`、副对角线 `row + col`，放置与撤销都是 O(1)。解数独按空格顺序逐个填，用行、列、宫三个集合记录已出现的数字，枚举 1 到 9，冲突则跳过；某个空格无解时回溯到上一个空格。两者都是回溯，只是约束条件不同。

**代码：**

```js
function solveNQueens(n) {
    const res = [];
    const cols = new Set();
    const diag1 = new Set();
    const diag2 = new Set();
    const board = Array.from({ length: n }, () => '.'.repeat(n));
    function backtrack(row) {
        if (row === n) {
            res.push([...board]);
            return;
        }
        for (let col = 0; col < n; col++) {
            if (cols.has(col) || diag1.has(row - col) || diag2.has(row + col)) {
                continue;
            }
            cols.add(col);
            diag1.add(row - col);
            diag2.add(row + col);
            board[row] = board[row].slice(0, col) + 'Q' + board[row].slice(col + 1);
            backtrack(row + 1);
            board[row] = board[row].slice(0, col) + '.' + board[row].slice(col + 1);
            cols.delete(col);
            diag1.delete(row - col);
            diag2.delete(row + col);
        }
    }
    backtrack(0);
    return res;
}

function solveSudoku(board) {
    const rows = Array.from({ length: 9 }, () => new Set());
    const cols = Array.from({ length: 9 }, () => new Set());
    const boxes = Array.from({ length: 9 }, () => new Set());
    const empty = [];
    for (let r = 0; r < 9; r++) {
        for (let c = 0; c < 9; c++) {
            if (board[r][c] === '.') {
                empty.push([r, c]);
                continue;
            }
            const v = board[r][c];
            rows[r].add(v);
            cols[c].add(v);
            boxes[Math.floor(r / 3) * 3 + Math.floor(c / 3)].add(v);
        }
    }
    function fill(index) {
        if (index === empty.length) return true;
        const [r, c] = empty[index];
        const b = Math.floor(r / 3) * 3 + Math.floor(c / 3);
        for (let d = 1; d <= 9; d++) {
            const v = String(d);
            if (rows[r].has(v) || cols[c].has(v) || boxes[b].has(v)) continue;
            board[r][c] = v;
            rows[r].add(v);
            cols[c].add(v);
            boxes[b].add(v);
            if (fill(index + 1)) return true;
            board[r][c] = '.';
            rows[r].delete(v);
            cols[c].delete(v);
            boxes[b].delete(v);
        }
        return false;
    }
    fill(0);
}
```

**复杂度：** N 皇后为 O(n!)，实际因剪枝远小于阶乘；解数独最坏 O(9^m)，`m` 为空格数，约束剪枝后通常很快。空间 O(n) 与 O(1)（数独固定 9 × 9）。

**边界与坑：**

- N 皇后按行递归，天然避免行冲突，不需要额外的行集合。
- 主对角线用 `row - col`，副对角线用 `row + col`，两者不能混。
- 修改棋盘后必须撤销，否则后续分支被污染。
- 数独的宫下标是 `(r/3)*3 + c/3`，行列都要整除 3。

**面试怎么答：** 先说「N 皇后是排列问题的约束版」，用三个集合把冲突判断降到 O(1)。解数独强调「先扫描记录已有数字，再对空格回溯」，并说明返回值用于提前终止。被问优化时，答可以优先选择候选数字最少的空格，或使用位运算压缩状态。

**易错点：**

- 用二维数组逐格检查冲突，复杂度升高。
- 撤销时只恢复棋盘，忘记从三个集合中删除。
- 数独填完一个解后继续搜索，覆盖了正确答案。
- 对角线集合用 `row + col` 与 `row - col` 写反，冲突判断失效。

## 11. 单词搜索与岛屿数量

**题目：** 单词搜索：在二维字符网格中判断是否存在一条路径按顺序拼出单词，路径只能上下左右移动，同一格子不能重复使用。岛屿数量：`'1'` 表示陆地、`'0'` 表示水，求四方向相连的陆地岛屿个数。示例：

```js
exist([['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], 'ABCCED'); // true
numIslands([['1','1','0'],['1','0','0'],['0','0','1']]); // 2
```

**思路：** 单词搜索是网格上的回溯：从每个格子出发，若当前字符匹配就继续向四个方向递归，进入前把格子改成特殊字符表示已访问，递归结束再恢复。因为不能重复使用，必须原地修改并撤销，不能只用一个全局 `visited` 而不回溯。岛屿数量是连通分量问题：遇到 `'1'` 就把答案加一，然后用 DFS 或 BFS 把整块陆地淹没成 `'0'`，每个格子只访问一次。

**代码：**

```js
function exist(board, word) {
    if (!board.length || !board[0].length) return false;
    const rows = board.length;
    const cols = board[0].length;
    function dfs(r, c, k) {
        if (k === word.length) return true;
        if (r < 0 || r >= rows || c < 0 || c >= cols) return false;
        if (board[r][c] !== word[k]) return false;
        const ch = board[r][c];
        board[r][c] = '#';
        const found = dfs(r + 1, c, k + 1) ||
            dfs(r - 1, c, k + 1) ||
            dfs(r, c + 1, k + 1) ||
            dfs(r, c - 1, k + 1);
        board[r][c] = ch;
        return found;
    }
    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            if (dfs(r, c, 0)) return true;
        }
    }
    return false;
}

function numIslands(grid) {
    const rows = grid.length;
    if (!rows) return 0;
    const cols = grid[0].length;
    let count = 0;
    function sink(r, c) {
        if (r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] !== '1') {
            return;
        }
        grid[r][c] = '0';
        sink(r + 1, c);
        sink(r - 1, c);
        sink(r, c + 1);
        sink(r, c - 1);
    }
    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            if (grid[r][c] === '1') {
                count++;
                sink(r, c);
            }
        }
    }
    return count;
}
```

**复杂度：** 单词搜索时间 O(m·n·3^L)，`L` 为单词长度，首格最多四个方向、之后最多三个；空间 O(L)。岛屿数量时间 O(mn)，每个格子只处理一次；空间 O(mn)，为递归栈最坏情况。

**边界与坑：**

- 网格为空或单词为空要先处理，空单词通常返回 true。
- 单词长度超过格子总数时不可能找到，可以提前剪枝。
- 单词搜索必须回溯恢复字符，否则其他起点无法复用该格子。
- 岛屿只算四方向，斜对角不算连通。
- 原地修改会破坏输入，若调用方需要保留原数组，应使用 `visited` 或拷贝。

**面试怎么答：** 两个问题都归为「网格 DFS」，但目的不同：单词搜索是路径匹配，需要回溯；岛屿数量是连通块染色，不需要回溯。讲清「进入前标记、离开时恢复」与「访问后永久标记」的区别，这是最容易混淆的点。

**易错点：**

- 单词搜索只标记不恢复，后续分支被错误剪断。
- 边界判断放在字符比较之后，访问越界。
- 岛屿用 `'0'` 与数字 `0` 比较，类型不一致。
- 把八方向连通当成四方向，答案偏小。

## 12. 贪心与 DP 的边界

**题目：** 零钱兑换：给定硬币面额和金额，求凑出金额的最少硬币数，凑不出返回 -1。用贪心能否解决？再以「无重叠区间」说明贪心何时正确。示例：

```js
coinChange([1, 3, 4], 6); // 2，3 + 3；贪心会得到 4 + 1 + 1 = 3
eraseOverlapIntervals([[1,2],[2,3],[3,4],[1,3]]); // 1，移除 [1,3]
```

**思路：** 贪心在零钱兑换上会失败：面额 `[1, 3, 4]`、金额 6，贪心先取 4，剩下只能用两个 1，共 3 枚，而最优是两枚 3。原因是贪心只考虑「当前最大面额」，没有考虑剩余金额的可组合性，不满足贪心选择性质。正确做法是 DP：`dp[a] = min(dp[a - coin] + 1)`，枚举最后一枚硬币。无重叠区间则满足贪心：按右端点排序，每次选择结束最早且与已选区间不冲突的区间，用交换论证可证明最优。

**代码：**

```js
function coinChange(coins, amount) {
    const dp = new Array(amount + 1).fill(Infinity);
    dp[0] = 0;
    for (let a = 1; a <= amount; a++) {
        for (const coin of coins) {
            if (coin <= a && dp[a - coin] + 1 < dp[a]) {
                dp[a] = dp[a - coin] + 1;
            }
        }
    }
    return dp[amount] === Infinity ? -1 : dp[amount];
}

function eraseOverlapIntervals(intervals) {
    if (intervals.length === 0) return 0;
    intervals.sort((a, b) => a[1] - b[1]);
    let removed = 0;
    let end = -Infinity;
    for (const [start, finish] of intervals) {
        if (start >= end) {
            end = finish;
        } else {
            removed++;
        }
    }
    return removed;
}
// 跳跃游戏：维护能到达的最远下标
function canJump(nums) {
    let farthest = 0;
    for (let i = 0; i < nums.length; i++) {
        if (i > farthest) return false;
        farthest = Math.max(farthest, i + nums[i]);
    }
    return true;
}
```

**复杂度：** 零钱兑换 O(amount × n)，空间 O(amount)；无重叠区间排序 O(n log n)，扫描 O(n)，空间 O(log n)（排序栈）。

**边界与坑：**

- 金额为 0 返回 0；硬币为空或无法凑出返回 -1。
- 零钱兑换的外层是金额、内层是硬币，得到的是「最少硬币数」；求组合数时循环顺序不同。
- 区间调度按右端点排序，按左端点排序会得到错误答案。
- `start >= end` 表示不重叠，端点相接算不冲突，具体要看题目定义。

**面试怎么答：** 先给反例说明贪心不成立，再总结贪心的两个前提：贪心选择性质与最优子结构。零钱兑换不满足前者，所以用 DP；区间调度满足，用交换论证证明「选最早结束的区间不会让后续更差」。最后补一句「无法证明贪心正确时，优先考虑 DP」。

**易错点：**

- 认为人民币面额体系下贪心永远正确，忽略题目可能给任意面额。
- 零钱兑换初始化 `dp[0]` 后忘记把其余位置设为 `Infinity`。
- 区间调度统计「保留数量」与「移除数量」时公式写反。
- 用 `start > end` 判断重叠，端点相接的区间被误删。
