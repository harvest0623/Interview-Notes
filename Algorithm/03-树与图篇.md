## 1. 二叉树遍历（递归 / 迭代 / Morris）

**题目：** 给定二叉树根节点，返回前序、中序、后序遍历序列。前序为「根左右」，中序为「左根右」，后序为「左右根」。示例：

```js
// 树：1(左2(左4,右5), 右3(右6))
// pre [1,2,4,5,3,6] / in [4,2,5,1,3,6] / post [4,5,2,6,3,1]
```

**思路：** 递归按「访问根、递归左、递归右」的顺序写，时间 O(n)、空间 O(h)，`h` 为树高；链状树会爆栈，所以要会显式栈。三种序的迭代差别在访问时机：前序在出栈时访问，中序在「左子树走到底」后弹出时访问，后序等左右子树都完成，可以用「根右左」的顺序遍历再整体反转。Morris 遍历借助叶子节点空的 `right` 指针临时指向中序后继，遍历后还原，把额外空间降到 O(1)，代价是短暂修改树结构。

**代码：**

```js
function TreeNode(val, left = null, right = null) { this.val = val; this.left = left; this.right = right; }
function traverse(root, order) {
    const res = [];
    function dfs(node) {
        if (!node) return;
        if (order === 'pre') res.push(node.val);
        dfs(node.left);
        if (order === 'in') res.push(node.val);
        dfs(node.right);
        if (order === 'post') res.push(node.val);
    }
    dfs(root);
    return res;
}

function preorderIterative(root) {
    const res = [], stack = root ? [root] : [];
    while (stack.length) {
        const node = stack.pop();
        res.push(node.val);
        if (node.right) stack.push(node.right);
        if (node.left) stack.push(node.left);
    }
    return res;
}
function inorderIterative(root) {
    const res = [], stack = [];
    let cur = root;
    while (stack.length || cur) {
        while (cur) {
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();
        res.push(cur.val);
        cur = cur.right;
    }
    return res;
}

function postorderIterative(root) {
    const res = [], stack = root ? [root] : [];
    while (stack.length) {
        const node = stack.pop();
        res.push(node.val);
        if (node.left) stack.push(node.left);
        if (node.right) stack.push(node.right);
    }
    return res.reverse();
}

function morrisInorder(root) {
    const res = [];
    let cur = root;
    while (cur) {
        if (!cur.left) {
            res.push(cur.val);
            cur = cur.right;
            continue;
        }
        let pre = cur.left;
        while (pre.right && pre.right !== cur) {
            pre = pre.right;
        }
        if (!pre.right) {
            pre.right = cur;
            cur = cur.left;
        } else {
            pre.right = null;
            res.push(cur.val);
            cur = cur.right;
        }
    }
    return res;
}
```

**复杂度：** 时间 O(n)；递归与显式栈空间 O(h)，Morris 空间 O(1)。

**边界与坑：**

- 空树返回空数组，不要返回 `[null]`。
- 后序的「反转法」依赖先压左再压右，顺序写反就得不到后序。
- Morris 结束后必须还原线索，否则树结构被破坏。

**面试怎么答：** 先写递归并说明 O(h) 栈空间，再主动补充「树很深时改成显式栈」。被追问空间优化时给出 Morris，讲清线索的建立与拆除，指出时间仍是 O(n)。后序迭代讲「根右左 + 反转」或「last 指针」两种思路即可。

**易错点：**

- 前序迭代先压左再压右，输出变成根右左。
- 中序循环只写 `while (stack.length)`，漏掉 `cur` 非空的情况。
- 后序反转法压栈顺序写成先右后左，结果错误。
- Morris 拆线索时忘记 `pre.right = null`，原树被破坏。

## 2. 层序遍历与锯齿遍历

**题目：** 返回二叉树的层序遍历结果，每层一个子数组；进阶实现锯齿形层序遍历，第一层从左到右，第二层从右到左，交替进行。示例：

```js
// 树：3 的左 9，右 20（20 的左 15、右 7）
levelOrder(root);       // [[3], [9, 20], [15, 7]]
zigzagLevelOrder(root); // [[3], [20, 9], [15, 7]]
```

**思路：** 用队列做 BFS，但普通出队会丢掉层边界，必须在每轮循环开头记录当前层的节点数 `size`，一次性处理完这一层。锯齿形只改变写入方向：偶数层正序、奇数层逆序，最省事的写法是每层照常收集，结束时对奇数层 `reverse()`，整体仍是 O(n)，不要用 `unshift` 逐个头插，那是 O(n²)。

**代码：**

```js
function levelOrder(root) {
    if (!root) return [];
    const res = [];
    const queue = [root];
    while (queue.length) {
        const size = queue.length;
        const level = [];
        for (let i = 0; i < size; i++) {
            const node = queue.shift();
            level.push(node.val);
            if (node.left) queue.push(node.left);
            if (node.right) queue.push(node.right);
        }
        res.push(level);
    }
    return res;
}

function zigzagLevelOrder(root) {
    if (!root) return [];
    const res = [];
    const queue = [root];
    let leftToRight = true;
    while (queue.length) {
        const size = queue.length;
        const level = [];
        for (let i = 0; i < size; i++) {
            const node = queue.shift();
            level.push(node.val);
            if (node.left) queue.push(node.left);
            if (node.right) queue.push(node.right);
        }
        if (!leftToRight) level.reverse();
        res.push(level);
        leftToRight = !leftToRight;
    }
    return res;
}
```

**复杂度：**

| 指标 | 复杂度 | 说明 |
| --- | --- | --- |
| 时间 | O(n) | 每个节点进出队一次，反转总计 O(n) |
| 空间 | O(w) | `w` 为最大层宽，满二叉树约 n/2 |

**边界与坑：**

- 空树返回 `[]`，不要返回 `[[]]`。
- 每轮必须先用 `size` 快照，边遍历边 `push` 会打乱层边界。
- 锯齿的奇偶判断基于层下标，第一层（下标 0）是从左到右。
- 队列用数组 `shift()` 是 O(n)，数据量大时应用头指针或双端队列。

**面试怎么答：** 强调「BFS + 每层 size 快照」是模板，所有层序变体都从这里改。锯齿只需在收集后按层反转，或遍历时按方向头插，说明反转写法更稳。被追问空间时答 O(w)，并补充可用 DFS 加深度下标实现层序，但层内顺序与锯齿不便控制。

**易错点：**

- 在 `for` 循环里直接写 `queue.length`，层边界被打破。
- 锯齿用 `unshift` 头插，复杂度退化到 O(n²)。
- 忘记空树判断，访问 `node.val` 时报错。
- 把锯齿的第一层写成从右到左，与题意相反。

## 3. 二叉树的最大深度与直径

**题目：** 求二叉树的最大深度；进阶求直径。直径是任意两个节点之间路径边数的最大值，路径不一定经过根节点。示例：

```js
// 树：1 的左 2（2 的左 4、右 5），1 的右 3
maxDepth(root);              // 3
diameterOfBinaryTree(root);  // 3，路径 4-2-1-3 或 5-2-1-3
```

**思路：** 最大深度是左右子树深度的较大值加一。直径的暴力做法是对每个节点求左右深度再相加，复杂度 O(n²)；最优做法是后序遍历时顺手计算：经过当前节点的最长路径为 `left + right`，用它更新全局答案，函数只返回单边最大深度，整体 O(n)。关键点是直径不一定经过根，因此答案必须用全局变量维护。

**代码：**

```js
function maxDepth(root) {
    if (!root) return 0;
    return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
}

function diameterOfBinaryTree(root) {
    let diameter = 0;
    function depth(node) {
        if (!node) return 0;
        const left = depth(node.left);
        const right = depth(node.right);
        diameter = Math.max(diameter, left + right);
        return Math.max(left, right) + 1;
    }
    depth(root);
    return diameter;
}

// 迭代求深度：BFS 的层数
function maxDepthIterative(root) {
    if (!root) return 0;
    let depth = 0;
    let queue = [root];
    while (queue.length) {
        depth++;
        const next = [];
        for (const node of queue) {
            if (node.left) next.push(node.left);
            if (node.right) next.push(node.right);
        }
        queue = next;
    }
    return depth;
}
```

**复杂度：** 时间 O(n)，每个节点只访问一次；空间 O(h)，为递归栈深度，最坏 O(n)。

**边界与坑：**

- 空树深度为 0，直径为 0。
- 直径按「边数」计算，若题目要求节点数，需要把答案加一。
- 全局答案不能在递归里直接 `return left + right`，否则父节点拿到的是错误深度。
- 只有左子树或只有右子树时，直径是单边深度。

**面试怎么答：** 先说最大深度是标准后序递归。直径问题指出暴力是 O(n²)，再用「返回值管深度、全局变量管直径」的双职责写法降到 O(n)。强调直径不一定过根，这是与「根到叶最长路径」的核心区别。

**易错点：**

- 在 `depth` 中返回 `left + right + 1`，导致上层深度计算错误。
- 把直径初始化成 0 后忘记更新，单节点树返回 0 是正确的，但链状树必须更新。
- 混淆边数与节点数，答案差一。
- 用层序遍历求直径，层宽与路径长度无关。

## 4. 最近公共祖先

**题目：** 给定二叉树和两个节点 `p`、`q`，返回它们的最近公共祖先（LCA）。示例：

```js
// 树：3 的左 5（5 的左 6、右 2（2 的左 7、右 4）），3 的右 1（1 的左 0、右 8）
lowestCommonAncestor(root, node5, node1); // 3
lowestCommonAncestor(root, node5, node4); // 5
```

**思路：** 暴力做法是从 `p` 向上找所有祖先，再用集合匹配 `q` 的祖先，需要父指针，空间 O(n)。递归最优解基于后序：当前节点为空或等于 `p`、`q` 时直接返回；否则递归左右子树。若左右都返回非空，说明两节点分居两侧，当前节点就是 LCA；若只有一侧非空，说明两个节点都在那一侧，返回该侧结果。每个节点访问一次，O(n)。

**代码：**

```js
function lowestCommonAncestor(root, p, q) {
    if (!root || root === p || root === q) return root;
    const left = lowestCommonAncestor(root.left, p, q);
    const right = lowestCommonAncestor(root.right, p, q);
    if (left && right) return root;
    return left || right;
}

// 二叉搜索树可以利用大小关系，迭代到分叉点
function lowestCommonAncestorBST(root, p, q) {
    while (root) {
        if (p.val < root.val && q.val < root.val) {
            root = root.left;
        } else if (p.val > root.val && q.val > root.val) {
            root = root.right;
        } else {
            return root;
        }
    }
    return null;
}

// 通用做法：记录父节点，把 p 的祖先放进集合，再沿 q 向上找交集
function lowestCommonAncestorWithParent(root, p, q) {
    const parent = new Map();
    const stack = [root];
    while (stack.length) {
        const node = stack.pop();
        if (node.left) {
            parent.set(node.left, node);
            stack.push(node.left);
        }
        if (node.right) {
            parent.set(node.right, node);
            stack.push(node.right);
        }
    }
    const ancestors = new Set();
    for (let cur = p; cur; cur = parent.get(cur)) {
        ancestors.add(cur);
    }
    for (let cur = q; cur; cur = parent.get(cur)) {
        if (ancestors.has(cur)) return cur;
    }
    return null;
}
```

**复杂度：**

| 版本 | 时间 | 空间 |
| --- | --- | --- |
| 普通二叉树递归 | O(n) | O(h) |
| 父指针 + 祖先集合 | O(n) | O(n) |
| BST 迭代 | O(h) | O(1) |

**边界与坑：**

- 题目保证 `p`、`q` 存在且不重复；若允许不存在，需要额外校验。
- 一个节点是另一个的祖先时，直接返回上层那个节点，递归写法天然正确。
- BST 版本必须用「同侧则继续下探、分叉即答案」的判定，不能只比较一个节点。
- 用值相等代替节点引用相等，在存在重复值的普通二叉树中会出错。

**面试怎么答：** 先讲递归的三种返回情况，突出「左右都非空就是分叉点」。若是 BST，主动给出 O(h)、O(1) 的迭代解。被追问「节点没有父指针怎么办」时，说明递归本身就是自底向上回溯，不需要父指针。

**易错点：**

- 把「只有一侧非空」误判为当前节点是 LCA。
- BST 版本写成 `if (p.val < root.val) root = root.left`，忽略 `q` 的位置。
- 空树或 `p`、`q` 为空时没有兜底。
- 用 `p.val === q.val` 判断同一节点，重复值场景出错。

## 5. 二叉搜索树的验证与增删

**题目：** 实现三个操作：验证一棵树是否为合法 BST；插入一个值；删除一个值并保持 BST 性质。示例：

```js
// 合法 BST：5 的左 3（左 1、右 4），右 8（左 7、右 9）
isValidBST(root);        // true
insertIntoBST(root, 2);  // 插入后仍为合法 BST
deleteNode(root, 3);     // 删除后仍为合法 BST
```

**思路：** 验证不能只比较「父与子」，必须给每个节点带上开区间 `(low, high)`，左子树收紧上界、右子树收紧下界；也可以中序遍历检查严格递增。插入沿大小关系走到空位。删除分三种情况：无子节点直接删；只有一个孩子用孩子顶替；有两个孩子时用右子树最小节点（中序后继）替换值，再递归删除后继。

**代码：**

```js
function isValidBST(root) {
    function check(node, low, high) {
        if (!node) return true;
        if (node.val <= low || node.val >= high) return false;
        return check(node.left, low, node.val) &&
            check(node.right, node.val, high);
    }
    return check(root, -Infinity, Infinity);
}

function insertIntoBST(root, val) {
    if (!root) return new TreeNode(val);
    if (val < root.val) {
        root.left = insertIntoBST(root.left, val);
    } else if (val > root.val) {
        root.right = insertIntoBST(root.right, val);
    }
    return root;
}

function deleteNode(root, key) {
    if (!root) return null;
    if (key < root.val) {
        root.left = deleteNode(root.left, key);
    } else if (key > root.val) {
        root.right = deleteNode(root.right, key);
    } else {
        if (!root.left) return root.right;
        if (!root.right) return root.left;
        let successor = root.right;
        while (successor.left) {
            successor = successor.left;
        }
        root.val = successor.val;
        root.right = deleteNode(root.right, successor.val);
    }
    return root;
}
```

**复杂度：**

| 操作 | 平均时间 | 最坏时间 | 空间 |
| --- | --- | --- | --- |
| 验证 | O(n) | O(n) | O(h) |
| 插入 | O(log n) | O(n) | O(h) |
| 删除 | O(log n) | O(n) | O(h) |

最坏情况是 BST 退化成链。

**边界与坑：**

- 验证必须用上下界，不能只判断 `node.left.val < node.val`。
- BST 通常要求严格不等，重复值是否允许要与题目确认。
- 删除有两个孩子的节点时，用右子树最小值或左子树最大值都可以。
- 插入重复值时通常约定不插入，或规定插入到某一侧，需与面试官确认。

**面试怎么答：** 验证先说「中序严格递增」这个等价条件，再写上下界递归，说明为什么单看父子关系不够。删除重点讲三种情况，特别是双子节点用中序后继替换。最后补一句 BST 的复杂度依赖树高，工程中会用 AVL 或红黑树保证 O(log n)。

**易错点：**

- 验证时只传当前节点值作为边界，没有继承祖先约束。
- 删除双子节点后忘记递归删除后继，树中出现重复值。
- 插入时没有把返回值接回 `root.left` 或 `root.right`。
- 用 `<=` 判断左子树，导致重复值被判为合法。

## 6. 从前序与中序构造二叉树

**题目：** 给定前序遍历和中序遍历数组（元素不重复），重建二叉树。示例：

```js
const preorder = [3, 9, 20, 15, 7];
const inorder = [9, 3, 15, 20, 7];
// 构造结果：3 的左 9，右 20（20 的左 15、右 7）
```

**思路：** 前序的第一个元素是根，在中序中找到它的位置，左边是左子树、右边是右子树。暴力每次线性查找根的位置，总复杂度 O(n²)。用哈希表预处理「值到中序下标」的映射，每次 O(1) 定位，递归区间划分，总复杂度 O(n)。递归参数用四个下标描述前序区间和中序区间，避免反复切片。

**代码：**

```js
function buildTree(preorder, inorder) {
    const index = new Map();
    for (let i = 0; i < inorder.length; i++) {
        index.set(inorder[i], i);
    }
    function build(preLeft, preRight, inLeft, inRight) {
        if (preLeft > preRight) return null;
        const rootVal = preorder[preLeft];
        const root = new TreeNode(rootVal);
        const mid = index.get(rootVal);
        const leftSize = mid - inLeft;
        root.left = build(preLeft + 1, preLeft + leftSize, inLeft, mid - 1);
        root.right = build(preLeft + leftSize + 1, preRight, mid + 1, inRight);
        return root;
    }
    return build(0, preorder.length - 1, 0, inorder.length - 1);
}

// 变体：后序 + 中序，根取后序末尾，先建右子树
function buildTreePostIn(postorder, inorder) {
    const index = new Map();
    inorder.forEach((val, i) => index.set(val, i));
    function build(postLeft, postRight, inLeft, inRight) {
        if (postLeft > postRight) return null;
        const rootVal = postorder[postRight];
        const root = new TreeNode(rootVal);
        const mid = index.get(rootVal);
        const rightSize = inRight - mid;
        root.right = build(postRight - rightSize, postRight - 1, mid + 1, inRight);
        root.left = build(postLeft, postRight - rightSize - 1, inLeft, mid - 1);
        return root;
    }
    return build(0, postorder.length - 1, 0, inorder.length - 1);
}
```

**复杂度：** 时间 O(n)，每个节点建一次、哈希查询 O(1)；空间 O(n)，哈希表与递归栈，最坏树高 O(n)。

**边界与坑：**

- 两数组长度必须相等且元素不重复，否则映射会覆盖。
- 空数组返回 `null`。
- 左子树长度是 `mid - inLeft`，不是 `mid`，后者在有偏移的递归中会错。
- 后序加中序构造同理，根取后序末尾，先建右子树。

**面试怎么答：** 先讲「前序定根、中序分左右」的核心，再指出线性查找会退化到 O(n²)，用哈希表优化到 O(n)。说明区间下标的含义，避免每次切片带来的额外空间。被追问「前序加后序能否唯一确定」时，答不能，因为无法区分只有一个孩子时它在左还是右。

**易错点：**

- 递归边界写成 `preLeft >= preRight`，漏掉叶子节点。
- 计算左子树长度时用了 `mid` 而不是 `mid - inLeft`。
- 右子树前序起点写成 `preLeft + leftSize`，少加一。
- 忘记处理元素重复的情况，哈希表只能存一个下标。

## 7. 路径总和与二叉树中的最大路径和

**题目：** 判断是否存在「根到叶子」的路径，节点值之和等于目标值；进阶求二叉树中的最大路径和，路径可以从任意节点出发、到任意节点结束，但必须沿父子边走且不重复经过节点。示例：

```js
// 树：5(左4(左11(左7,右2)), 右8(左13,右4(右1)))
hasPathSum(root, 22); // true，5 → 4 → 11 → 2
maxPathSum(root);     // 48，路径 7 → 11 → 4 → 5 → 8 → 13
```

**思路：** 路径总和用递归递减目标值，到达叶子时判断剩余值是否等于叶子的值；注意必须走到叶子，不能在中途节点提前返回。最大路径和的暴力做法是枚举每个节点作为转折点，分别求左右最大深度，O(n²)。最优解是后序遍历：函数返回「以当前节点为端点、向下的最大收益」，负增益直接舍弃为 0；在每个节点处用 `左增益 + 当前值 + 右增益` 更新全局答案。

**代码：**

```js
function hasPathSum(root, targetSum) {
    if (!root) return false;
    if (!root.left && !root.right) return root.val === targetSum;
    return hasPathSum(root.left, targetSum - root.val) ||
        hasPathSum(root.right, targetSum - root.val);
}

function pathSum(root, targetSum) {
    const res = [];
    const path = [];
    function dfs(node, rest) {
        if (!node) return;
        path.push(node.val);
        if (!node.left && !node.right && rest === node.val) {
            res.push([...path]);
        }
        dfs(node.left, rest - node.val);
        dfs(node.right, rest - node.val);
        path.pop();
    }
    dfs(root, targetSum);
    return res;
}

function maxPathSum(root) {
    let ans = -Infinity;
    function gain(node) {
        if (!node) return 0;
        const left = Math.max(gain(node.left), 0);
        const right = Math.max(gain(node.right), 0);
        ans = Math.max(ans, node.val + left + right);
        return node.val + Math.max(left, right);
    }
    gain(root);
    return ans;
}
```

**复杂度：** 时间 O(n)，每个节点访问一次；空间 O(h)，递归栈深度。

**边界与坑：**

- 路径总和要求终点是叶子，不能在中途节点判定成功。
- 最大路径和允许只取一个节点，空树无定义，题目通常保证至少一个节点。
- 节点全为负数时答案应是最大的那个负数，`ans` 必须初始化为 `-Infinity`。
- 增益为负时取 0，表示不选那棵子树，不能把负值继续向上传递。

**面试怎么答：** 先区分两个问题的路径定义：一个限制根到叶子，一个是任意节点到任意节点。路径总和是自顶向下递减；最大路径和是自底向上，讲清「函数返回单边增益、全局变量记录双分支路径」的分工。被追问负数处理时，答「增益与 0 取最大，保证不选负贡献子树」。

**易错点：**

- 路径总和写成 `if (root.val === targetSum) return true`，没有检查是否为叶子。
- 最大路径和直接返回 `left + right + node.val` 给父节点，路径出现分叉。
- 忘记把 `left`、`right` 与 0 取最大，负数节点拉低答案。
- 空树调用 `maxPathSum` 返回 `-Infinity`，需要与题目约定确认。

## 8. 堆与优先队列

**题目：** 手写一个最小堆，支持 `push`、`pop`、`peek`、`size`；并用它解决 TopK 问题：返回数组中出现频率最高的 `k` 个元素。示例：

```js
const heap = new MinHeap();
[3, 1, 5, 2].forEach((x) => heap.push(x));
heap.pop(); // 1
topKFrequent([1, 1, 1, 2, 2, 3], 2); // 包含 1 和 2，顺序不保证
```

**思路：** 堆是完全二叉树，用数组存储，下标 `i` 的孩子是 `2i+1`、`2i+2`，父亲是 `(i-1)/2`。插入时放到末尾再上浮；删除堆顶时把末尾元素换到根再下沉。建堆从最后一个非叶子节点向前下沉，复杂度 O(n)，比逐个插入的 O(n log n) 更优。TopK 维护一个大小为 `k` 的最小堆，堆顶是当前 k 个候选里最小的，新元素比堆顶大就替换，最终堆内即答案，时间 O(n log k)。

**代码：**

```js
class MinHeap {
    constructor(compare = (a, b) => a - b) {
        this.data = [];
        this.compare = compare;
    }
    size() {
        return this.data.length;
    }
    peek() {
        return this.data[0];
    }
    push(val) {
        this.data.push(val);
        this.siftUp(this.data.length - 1);
    }
    pop() {
        if (!this.data.length) return undefined;
        const top = this.data[0];
        const last = this.data.pop();
        if (this.data.length) {
            this.data[0] = last;
            this.siftDown(0);
        }
        return top;
    }
    siftUp(i) {
        while (i > 0) {
            const parent = (i - 1) >> 1;
            if (this.compare(this.data[parent], this.data[i]) <= 0) break;
            [this.data[parent], this.data[i]] = [this.data[i], this.data[parent]];
            i = parent;
        }
    }
    siftDown(i) {
        const n = this.data.length;
        while (true) {
            let smallest = i;
            const left = i * 2 + 1;
            const right = i * 2 + 2;
            if (left < n && this.compare(this.data[left], this.data[smallest]) < 0) {
                smallest = left;
            }
            if (right < n && this.compare(this.data[right], this.data[smallest]) < 0) {
                smallest = right;
            }
            if (smallest === i) break;
            [this.data[smallest], this.data[i]] = [this.data[i], this.data[smallest]];
            i = smallest;
        }
    }
}

function topKFrequent(nums, k) {
    const freq = new Map();
    for (const x of nums) {
        freq.set(x, (freq.get(x) || 0) + 1);
    }
    const heap = new MinHeap((a, b) => a[0] - b[0]);
    for (const [val, count] of freq) {
        heap.push([count, val]);
        if (heap.size() > k) heap.pop();
    }
    return heap.data.map((item) => item[1]);
}
```

**复杂度：**

| 操作 | 时间 | 说明 |
| --- | --- | --- |
| push / pop | O(log n) | 树高为 log n |
| peek | O(1) | 直接取数组首元素 |
| 建堆 | O(n) | 从 n/2 处向前下沉 |
| TopK | O(n log k) | 堆大小不超过 k |

**边界与坑：**

- 空堆 `pop` 返回 `undefined`，调用方要先判空。
- `k` 大于不同元素个数时，返回全部元素，不应报错。
- 比较器返回值必须严格符合「负数表示 a 优先」，写反会得到大顶堆。
- 下沉时先比较左右孩子，再与父节点交换，不能只比较左孩子。

**面试怎么答：** 先讲数组下标与完全二叉树的关系，再写 `siftUp`、`siftDown` 两个核心函数。被问「为什么建堆是 O(n)」时，答「按高度分层求和，大部分节点在底层且下沉次数少」。TopK 说明为什么用最小堆而不是最大堆：堆顶要作为淘汰门槛。

**易错点：**

- 孩子下标写成 `2i`、`2i+1`，根为 0 时会错位。
- `pop` 后忘记把末尾元素放到根，堆结构断裂。
- `siftDown` 只与左孩子比较，忽略右孩子更小的情况。
- TopK 用最大堆，导致无法快速淘汰最小值。

## 9. 图的表示与 DFS/BFS

**题目：** 用邻接表表示无向图，实现 DFS 与 BFS 遍历，并统计连通分量个数。示例：

```js
const edges = [[0, 1], [1, 2], [3, 4]];
const graph = buildGraph(5, edges);
dfs(graph, 0);            // [0, 1, 2]
bfs(graph, 0);            // [0, 1, 2]
countComponents(5, edges); // 2，{0,1,2} 与 {3,4}
```

**思路：** 邻接表用「顶点数长度的数组 + 每个顶点的邻居列表」，空间 O(V+E)，比邻接矩阵的 O(V²) 更适合稀疏图。DFS 用显式栈，入栈前不标记、出栈时标记，避免重复；若想保持邻居的原始顺序，倒序压栈。BFS 用队列，入队时立即标记，否则同一节点会被多次入队。连通分量就是外层循环对每个未访问顶点启动一次遍历。

**代码：**

```js
function buildGraph(n, edges) {
    const graph = Array.from({ length: n }, () => []);
    for (const [u, v] of edges) {
        graph[u].push(v);
        graph[v].push(u);
    }
    return graph;
}

function dfs(graph, start) {
    const visited = new Set();
    const order = [];
    const stack = [start];
    while (stack.length) {
        const node = stack.pop();
        if (visited.has(node)) continue;
        visited.add(node);
        order.push(node);
        for (let i = graph[node].length - 1; i >= 0; i--) {
            if (!visited.has(graph[node][i])) {
                stack.push(graph[node][i]);
            }
        }
    }
    return order;
}

function bfs(graph, start) {
    const visited = new Set([start]);
    const order = [];
    const queue = [start];
    for (let head = 0; head < queue.length; head++) {
        const node = queue[head];
        order.push(node);
        for (const next of graph[node]) {
            if (!visited.has(next)) {
                visited.add(next);
                queue.push(next);
            }
        }
    }
    return order;
}

function countComponents(n, edges) {
    const graph = buildGraph(n, edges);
    const visited = new Array(n).fill(false);
    let count = 0;
    for (let i = 0; i < n; i++) {
        if (visited[i]) continue;
        count++;
        const stack = [i];
        visited[i] = true;
        while (stack.length) {
            const node = stack.pop();
            for (const next of graph[node]) {
                if (!visited[next]) {
                    visited[next] = true;
                    stack.push(next);
                }
            }
        }
    }
    return count;
}
```

**复杂度：** 时间 O(V+E)，每个顶点入队或入栈一次、每条边被检查两次（无向图）；空间 O(V+E)，邻接表与访问集合。

**边界与坑：**

- 自环与重边不影响遍历，但会影响边计数。
- 非连通图必须从每个未访问顶点重新启动，不能只遍历起点。
- BFS 若在出队时才标记，同一节点可能重复入队。
- 递归 DFS 在十万级顶点时可能爆栈，优先用显式栈。

**面试怎么答：** 先说邻接表与邻接矩阵的取舍：稀疏图用邻接表，稠密图或需要 O(1) 判边用矩阵。DFS 讲清「入栈/出栈标记」的两种写法及差异，BFS 强调入队即标记。最后补一句连通分量是外层再包一层循环。

**易错点：**

- 邻接表只加 `u → v`，忘记无向图要反向再加 `v → u`。
- DFS 在入栈时标记却在出栈时输出，顺序可能与预期不符。
- BFS 用 `shift()` 出队，复杂度退化到 O(V²)。
- 统计连通分量时漏掉孤立顶点。

## 10. 拓扑排序与课程表

**题目：** 给定课程数与先修关系 `[course, pre]`，判断能否完成所有课程；若能，返回一种学习顺序。示例：

```js
const prerequisites = [[1, 0], [2, 1], [3, 2]];
courseOrder(4, prerequisites); // [0, 1, 2, 3]
canFinish(4, [[1, 0], [0, 1]]); // false，存在环
```

**思路：** 拓扑排序只适用于有向无环图。Kahn 算法统计每个节点的入度，先把入度为 0 的节点入队，出队时把它加入结果并让所有后继入度减一，减到 0 就入队。若最终结果包含所有节点，说明无环；否则剩下的节点构成环。DFS 版本用三色标记：未访问、访问中、已完成，遇到「访问中」的节点就说明有环。

**代码：**

```js
function courseOrder(numCourses, prerequisites) {
    const graph = Array.from({ length: numCourses }, () => []);
    const indegree = new Array(numCourses).fill(0);
    for (const [course, pre] of prerequisites) {
        graph[pre].push(course);
        indegree[course]++;
    }
    const queue = [];
    for (let i = 0; i < numCourses; i++) {
        if (indegree[i] === 0) queue.push(i);
    }
    const order = [];
    for (let head = 0; head < queue.length; head++) {
        const cur = queue[head];
        order.push(cur);
        for (const next of graph[cur]) {
            indegree[next]--;
            if (indegree[next] === 0) queue.push(next);
        }
    }
    return order.length === numCourses ? order : [];
}

function canFinish(numCourses, prerequisites) {
    return courseOrder(numCourses, prerequisites).length === numCourses;
}

// DFS 三色标记：0 未访问，1 访问中，2 已完成
function canFinishDFS(numCourses, prerequisites) {
    const graph = Array.from({ length: numCourses }, () => []);
    for (const [course, pre] of prerequisites) {
        graph[pre].push(course);
    }
    const state = new Array(numCourses).fill(0);
    function hasCycle(node) {
        if (state[node] === 1) return true;
        if (state[node] === 2) return false;
        state[node] = 1;
        for (const next of graph[node]) {
            if (hasCycle(next)) return true;
        }
        state[node] = 2;
        return false;
    }
    for (let i = 0; i < numCourses; i++) {
        if (state[i] === 0 && hasCycle(i)) return false;
    }
    return true;
}
```

**复杂度：** 时间 O(V+E)，每个节点与每条边各处理一次；空间 O(V+E)，邻接表、入度数组与队列。

**边界与坑：**

- 拓扑序不唯一，只要满足所有先修关系即可，不要与某个固定答案比较。
- 自环 `[i, i]` 会让入度永远无法降到 0，属于环。
- 重边不影响正确性，但会让入度多加几次，必须与邻接表中的边数一致。
- 图可能不连通，Kahn 从所有入度为 0 的节点同时开始。

**面试怎么答：** 先说明「拓扑排序等价于判断有向图是否有环」。Kahn 讲入度与队列，DFS 讲三色标记，两种都给出更稳妥。被问「为什么结果数量小于节点数就表示有环」时，答「环上的节点入度始终至少为 1，永远进不了队列」。

**易错点：**

- 建图方向写反，把 `pre → course` 写成 `course → pre`。
- 入度数组没有初始化或更新，导致队列一开始为空。
- DFS 只用一个 `visited` 布尔数组，无法区分「访问中」与「已完成」。
- 返回 `order` 时没有校验长度，把部分结果当成完整拓扑序。

## 11. 并查集与连通分量

**题目：** 实现并查集，支持 `find`、`union`，并统计连通分量个数；进阶判断一条边是否为冗余边（加入后仍连通）。示例：

```js
const uf = new UnionFind(5);
uf.union(0, 1);
uf.union(1, 2);
uf.union(3, 4);
uf.count; // 2，{0,1,2} 与 {3,4}
```

**思路：** 用数组记录每个节点的父节点，`find` 向上找到根；朴素实现可能退化成链，所以加路径压缩，把沿途节点直接挂到根上。`union` 按秩或按大小合并，把矮树挂到高树下，避免树高增长。两个优化结合后，单次操作的摊还复杂度为 O(α(n))，可近似看作 O(1)。连通分量个数用 `count` 维护，每次成功合并减一。

**代码：**

```js
class UnionFind {
    constructor(n) {
        this.parent = Array.from({ length: n }, (_, i) => i);
        this.rank = new Array(n).fill(0);
        this.count = n;
    }
    find(x) {
        while (x !== this.parent[x]) {
            this.parent[x] = this.parent[this.parent[x]];
            x = this.parent[x];
        }
        return x;
    }
    union(a, b) {
        const rootA = this.find(a);
        const rootB = this.find(b);
        if (rootA === rootB) return false;
        if (this.rank[rootA] < this.rank[rootB]) {
            this.parent[rootA] = rootB;
        } else if (this.rank[rootA] > this.rank[rootB]) {
            this.parent[rootB] = rootA;
        } else {
            this.parent[rootB] = rootA;
            this.rank[rootA]++;
        }
        this.count--;
        return true;
    }
}

function countComponentsUF(n, edges) {
    const uf = new UnionFind(n);
    for (const [a, b] of edges) {
        uf.union(a, b);
    }
    return uf.count;
}

// 冗余边：连接两个已经连通的点
function redundantConnection(edges) {
    const n = edges.length;
    const uf = new UnionFind(n + 1);
    for (const [a, b] of edges) {
        if (!uf.union(a, b)) return [a, b];
    }
    return [];
}
```

**复杂度：** 单次 `find` / `union` 摊还 O(α(n))，`α` 为反阿克曼函数，增长极慢；空间 O(n)。对 `m` 条边建图的总时间为 O(m α(n))。

**边界与坑：**

- 路径压缩写成递归时，极深链可能爆栈，迭代写法更稳。
- `union` 必须先找到两个根再比较秩，不能直接比较节点本身。
- 节点编号从 0 还是从 1 开始要与调用方一致，数组长度差一。
- 冗余边要求图最终是一棵树，边数必须为 `n`，否则结论不成立。

**面试怎么答：** 先写朴素 `find`，指出链状退化到 O(n)，再引出路径压缩与按秩合并。说明两个优化后复杂度是 O(α(n))，并强调「连通性、环检测、Kruskal」都是并查集的典型场景。冗余边问题解释为「加入一条边时两个端点已经同根」。

**易错点：**

- `find` 只做一次父指针更新，没有真正压缩到根。
- 按秩合并时把 `rank` 与节点值混用。
- 成功合并后忘记 `count--`，连通分量数偏大。
- 对无向图重复添加同一条边，误判为冗余边。

## 12. 最短路径（Dijkstra / Floyd）

**题目：** 给定带权有向图，求单源最短路径（Dijkstra）与任意两点最短路径（Floyd）。示例：

```js
const edges = [[0, 1, 1], [0, 2, 4], [1, 2, 2], [1, 3, 6], [2, 3, 3]];
dijkstra(4, edges, 0); // [0, 1, 3, 6]
floyd(4, edges);       // 0→3 的最短距离为 6
```

**思路：** Dijkstra 基于贪心：每次从未确定集合中取出距离最小的节点，用它松弛邻居，然后把它标记为已确定。朴素数组实现 O(V²)，适合稠密图；用小顶堆维护距离可做到 O((V+E) log V)，适合稀疏图。它要求边权非负，因为贪心假设「当前最小距离不会再被更短的路径更新」，负权会破坏这个前提。Floyd 是区间 DP：`dp[i][j]` 表示只允许经过前 `k` 个中间点时 `i` 到 `j` 的最短距离，三重循环枚举中间点，O(V³)，可处理负权但不可有负环。

**代码：**

```js
function dijkstra(n, edges, src) {
    const graph = Array.from({ length: n }, () => []);
    for (const [u, v, w] of edges) {
        graph[u].push([v, w]);
    }
    const dist = new Array(n).fill(Infinity);
    const used = new Array(n).fill(false);
    dist[src] = 0;
    for (let i = 0; i < n; i++) {
        let u = -1;
        for (let j = 0; j < n; j++) {
            if (!used[j] && (u === -1 || dist[j] < dist[u])) u = j;
        }
        if (u === -1 || dist[u] === Infinity) break;
        used[u] = true;
        for (const [v, w] of graph[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
            }
        }
    }
    return dist;
}

function floyd(n, edges) {
    const dist = Array.from({ length: n }, (_, i) =>
        Array.from({ length: n }, (_, j) => (i === j ? 0 : Infinity)));
    for (const [u, v, w] of edges) {
        dist[u][v] = Math.min(dist[u][v], w);
    }
    for (let k = 0; k < n; k++) {
        for (let i = 0; i < n; i++) {
            if (dist[i][k] === Infinity) continue;
            for (let j = 0; j < n; j++) {
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
    return dist;
}
```

**复杂度：**

| 算法 | 时间 | 空间 | 适用 |
| --- | --- | --- | --- |
| Dijkstra 数组 | O(V²) | O(V+E) | 稠密图、无负权 |
| Dijkstra 堆 | O((V+E) log V) | O(V+E) | 稀疏图、无负权 |
| Floyd | O(V³) | O(V²) | 多源、可负权、无负环 |

**边界与坑：**

- Dijkstra 不能处理负权边，负权要用 Bellman-Ford 或 SPFA。
- 不可达节点距离保持 `Infinity`，输出时要转成题目要求的表示。
- 有向图只加单向边；无向图每条边要加两个方向。
- Floyd 的三重循环中，中间点 `k` 必须放最外层，否则结果错误。
- 重边要取最小值，不能直接覆盖。

**面试怎么答：** 先讲 Dijkstra 的贪心正确性与「非负权」前提，再说明朴素与堆优化的适用场景。Floyd 重点讲状态定义「允许经过前 k 个中间点」，以及为什么 `k` 必须在外层。被问负权时，答用 Bellman-Ford，并能说出它通过 V-1 轮松弛检测负环。

**易错点：**

- Dijkstra 在节点出堆后没有跳过已确定的节点，重复松弛。
- 用 `dist[u] + w` 时没有判断 `dist[u]` 是否为 `Infinity`。
- Floyd 初始化忘记 `dist[i][i] = 0`。
- 把 Floyd 的循环顺序写成 `i, j, k`，枚举顺序失去 DP 含义。
