## 学习路径建议

```
语言基础篇（语法与语言特性，面试必答）
   ↓
进阶原理篇（内存 / GC / 面向对象底层，区分「会用」与「懂原理」）
   ↓
并发编程篇（GIL、多线程、多进程、协程，后端岗高频）
   ↓
常用库与工程化篇（依赖管理、测试、类型、打包——团队协作能力）
   ↓
实战与框架篇（Web 框架与工程实践，后端方向加分项）
```

> 面试策略：**语言基础 + 进阶原理是硬门槛**（几乎每场必问），**并发与 GIL 是分水岭**，**工程化与框架体现项目经验**。

## 核心速查表

**可变与不可变类型**

```
不可变（immutable）：int、float、bool、str、tuple、frozenset、bytes
可变（mutable）　　：list、dict、set、bytearray、自定义对象
规律：不可变对象作为函数参数「改不了原值」；可变对象传参是「引用传递」，函数内修改会影响外部
```

**深拷贝与浅拷贝**

```
赋值（=）　　：不复制，只是多一个名字指向同一对象
浅拷贝　　　：copy.copy()、list.copy()、dict.copy()、切片、copy 模块
　　　　　　  复制外层容器，内层元素仍是同一引用
深拷贝　　　：copy.deepcopy()，递归复制所有层级，递归引用会自动处理
```

**四大容器对比**

```
list  ：有序、可变、可重复、O(1) 索引、查找 O(n)
tuple ：有序、不可变、可重复、可作字典 key（需元素也可哈希）
dict  ：3.7+ 有序（插入序）、键唯一、查找/插入平均 O(1)、键须可哈希
set   ：无序（实际为哈希序）、元素唯一、查找平均 O(1)、元素须可哈希
```

**并发三件套选型**

```
IO 密集型   → 多线程（threading / ThreadPoolExecutor）或协程（asyncio）
CPU 密集型  → 多进程（multiprocessing / ProcessPoolExecutor），绕过 GIL
高并发网络  → asyncio（单线程事件循环，海量连接）
简单任务池  → concurrent.futures 的 ThreadPoolExecutor / ProcessPoolExecutor
```

**常用工程化工具链**

```
虚拟环境：venv（内置）、virtualenv、conda、uv
依赖管理：pip + requirements.txt、Poetry、PDM、uv
类型检查：mypy、pyright
代码规范：Ruff（lint + format，推荐）、Black、isort、flake8
测试框架：pytest（主流）、unittest（内置）、tox（多环境）
打包发布：build + twine、setuptools、hatchling
性能剖析：cProfile、line_profiler、memory_profiler、py-spy
```
