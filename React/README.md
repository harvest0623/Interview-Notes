## 核心速查表

**组件数据流**

```
父 → 子：props（只读）
子 → 父：回调函数
跨层级：Context / 状态管理库
```

**渲染触发时机**

```
state 变化 · 父组件重渲染 · Context 变化 · forceUpdate
```

**Hooks 使用规则**

```
1. 只在函数组件或自定义 Hook 顶层调用
2. 不在条件、循环、嵌套函数中调用
3. 调用顺序必须稳定
```
