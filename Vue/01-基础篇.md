## 1. Vue 是什么？有哪些特点？

**Vue** 是一款用于构建用户界面的**渐进式 JavaScript 框架**：核心库只关注视图层，可按需逐步引入路由、状态管理、构建工具等能力。

**核心特点：**

| 特点 | 说明 |
| --- | --- |
| **渐进式** | 可以只用核心库做局部增强，也可以搭建完整 SPA |
| **声明式渲染** | 用模板声明 UI 与数据的关系，无需手动操作 DOM |
| **响应式系统** | 数据变化自动驱动视图更新（Vue 3 基于 `Proxy`） |
| **组件化** | 单文件组件（SFC）把模板、逻辑、样式写在一起 |
| **指令系统** | `v-if`、`v-for`、`v-model` 等声明式操作 DOM |
| **虚拟 DOM** | 通过 Diff 计算最小更新，配合编译优化提升性能 |
| **上手快** | 模板语法贴近 HTML，文档完善，中文生态好 |

```vue
<script setup>
import { ref } from 'vue';
const count = ref(0);
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

**与 React 的区别：**

| | Vue | React |
| --- | --- | --- |
| 模板 | 模板 + 指令（编译期优化） | JSX（JS 表达能力） |
| 响应式 | 自动依赖追踪（Proxy） | 手动 `setState` + 不可变数据 |
| 更新粒度 | 组件级 + 编译优化 | 组件级（需 `memo` 手动优化） |
| 样式 | `scoped` 内置 | 需 CSS Modules / CSS-in-JS |
| 上手 | 更平缓 | 需要更多 JS 基础 |

## 2. Vue 2 与 Vue 3 的区别？

| 维度 | Vue 2 | Vue 3 |
| --- | --- | --- |
| **响应式** | `Object.defineProperty` | **`Proxy`** |
| **API 风格** | 选项式 API（Options API） | 选项式 + **组合式 API**（Composition API） |
| **代码组织** | 按选项分块（data/methods/computed） | 按逻辑关注点组织，可复用 |
| **根实例** | `new Vue()` | `createApp()` |
| **多根节点** | 单根节点 | 支持**多根节点**（Fragment） |
| **生命周期** | `beforeDestroy`/`destroyed` | 重命名为 `beforeUnmount`/`unmounted` |
| **Tree-shaking** | 不支持 | 支持（按需引入，体积更小） |
| **TypeScript** | 支持较弱 | **原生更好支持** |
| **v-model** | 组件上 `.sync` / `value+input` | 默认 `modelValue` + `update:modelValue`，支持多 `v-model` |
| **Diff** | 双端比较 | **最长递增子序列**优化移动 |
| **编译优化** | 无 | 静态提升、PatchFlag、Block Tree |
| **新组件** | —— | `Teleport`、`Suspense`、多 `v-model` |
| **大小** | 较大 | 核心更小（约 -40%） |
| **性能** | 好 | 更快（初次渲染/更新/内存更优） |

```js
// Vue 2
new Vue({ el: '#app', data: { count: 0 } });

// Vue 3
import { createApp } from 'vue';
createApp(App).mount('#app');
```

**要点：** Vue 3 的核心变化是「**Proxy 响应式 + 组合式 API + 编译优化 + Tree-shaking**」。

## 3. MVVM 是什么？

**MVVM = Model - View - ViewModel**，一种把 UI 与业务逻辑解耦的架构模式。

| 层 | 职责 |
| --- | --- |
| **Model** | 数据与业务逻辑（如 `data` 中的数据、接口返回） |
| **View** | 视图（模板、DOM） |
| **ViewModel** | 连接层，把 Model 转换为 View 可用的数据，并监听 View 的变化 |

**在 Vue 中的对应：**

- Model → `data` / `ref` / `reactive` 中的数据。
- View → `<template>` 模板。
- ViewModel → **Vue 实例**（负责响应式、数据劫持、视图更新、事件绑定）。

**核心是「双向数据绑定」：**

```
Model 变化 → ViewModel 通知 → View 更新
View 变化（如输入）→ ViewModel 监听 → Model 更新
```

**要点：**

- Vue **不是严格的 MVVM**，它更准确地说是「**响应式 + 声明式渲染**」；`ref` 直接操作 DOM 时就不在 MVVM 范畴。
- MVVM 的价值在于**开发者不用手动操作 DOM**，只需关注数据。

## 4. 模板语法与常用指令

**插值：**

```vue
<template>
  <p>{{ msg }}</p>            <!-- 文本插值 -->
  <p v-text="msg"></p>        <!-- 等价于 textContent -->
  <p v-html="htmlStr"></p>    <!-- 渲染 HTML（有 XSS 风险，慎用） -->
  <p>{{ count + 1 }}</p>      <!-- 支持表达式，不支持语句 -->
</template>
```

**常用指令：**

| 指令 | 作用 |
| --- | --- |
| `v-if` / `v-else-if` / `v-else` | 条件渲染（销毁/重建） |
| `v-show` | 条件显示（切换 `display`） |
| `v-for` | 列表渲染 |
| `v-bind`（`:`) | 动态绑定属性 |
| `v-on`（`@`） | 绑定事件 |
| `v-model` | 双向绑定表单 |
| `v-html` / `v-text` | 渲染 HTML / 文本 |
| `v-once` | 只渲染一次（静态内容优化） |
| `v-memo` | 缓存模板片段（Vue 3.2+） |
| `v-slot`（`#`） | 插槽 |
| `v-pre` | 跳过编译（显示原始 `{{}}`） |
| `v-cloak` | 编译完成前隐藏（避免闪现 `{{}}`） |

```vue
<template>
  <div :class="cls" :style="{ color }">
    <span v-if="visible" v-once>{{ staticText }}</span>
    <ul>
      <li v-for="(item, index) in list" :key="item.id">{{ index }} - {{ item.name }}</li>
    </ul>
    <input v-model="keyword" />
  </div>
</template>
```

**要点：**

- `{{ }}` 内是**表达式**（不能写 `if`/`for` 语句）。
- 动态参数：`:[attrName]="value"`，`@[eventName]="handler"`。
- 指令本质是编译期转换：`v-bind` → `:attr` → 渲染函数的 props。

## 5. v-if 与 v-show 的区别？

| | `v-if` | `v-show` |
| --- | --- | --- |
| 原理 | 条件为假时**销毁**元素（或创建） | 始终渲染，切换 `display: none` |
| 初始渲染开销 | 条件为假时更低（不渲染） | 始终渲染，开销更高 |
| 切换开销 | 高（销毁/重建组件与事件） | 低（只改样式） |
| 是否支持 `<template>` | 支持 | 不支持（需挂在元素上） |
| 是否触发生命周期 | 是（`mounted`/`unmounted`） | 否 |
| 适用场景 | **切换不频繁**、条件很少变 | **频繁切换**（Tab、下拉） |

```vue
<div v-if="type === 'A'">A</div>
<div v-show="type === 'A'">A</div>
```

**要点：**

- `v-if` 有**惰性**：初始为假时不渲染任何内容。
- `v-if` **权限判断**更安全（假值时不渲染 DOM，无法从 DOM 直接看到）。
- 频繁切换用 `v-show`，初始条件为假用 `v-if`。

## 6. v-for 与 key 的作用

```vue
<ul>
  <li v-for="(item, index) in list" :key="item.id">
    {{ index }} - {{ item.name }}
  </li>
</ul>
```

**`v-for` 用法：**

```vue
<!-- 数组 -->
<div v-for="(item, index) in list" :key="index"></div>
<!-- 对象 -->
<div v-for="(value, key, index) in obj" :key="key"></div>
<!-- 数字 -->
<div v-for="n in 10" :key="n"></div>
```

**key 的作用：** 帮助 Vue 的 Diff 算法**识别节点身份**，从而**正确复用**已有 DOM、减少不必要的移动与重建。

**为什么不要用 `index` 作 key？**

- 列表**顺序变化**（插入/删除/排序）时索引错位，导致复用错误的 DOM。
- 对**带输入框、内部状态**的项会串位。

```vue
<!-- 反例 -->
<li v-for="(item, index) in list" :key="index"></li>
<!-- 正例 -->
<li v-for="(item) in list" :key="item.id"></li>
```

**注意：**

- **`v-for` 与 `v-if` 不要用在同一个元素上**：
  - Vue 2 中 `v-for` 优先级更高，`v-if` 会重复执行，浪费性能。
  - Vue 3 中 `v-if` 优先级更高，会因访问不到 `v-for` 的变量而报错。
  - 正确做法：用 `<template v-for>` 包裹，或在**外层**加 `v-if` / 先算好过滤后的列表。
- 用 `index` 作 key 只在「**列表纯静态、不会重排**」时才勉强可接受。

## 7. computed 与 watch 的区别？

| | `computed` | `watch` |
| --- | --- | --- |
| 用途 | **派生新数据**（由已有数据计算） | **执行副作用**（请求、日志、操作 DOM） |
| 是否有缓存 | **有**（依赖不变不重算） | 无缓存（每次变化都触发） |
| 是否返回值 | 必须返回一个值 | 不要求返回值 |
| 默认行为 | 惰性求值（首次访问才计算） | 立即侦听设置项（`immediate`） |
| 适合 | 模板中用到的派生值 | 数据变化后做异步/副作用操作 |
| 深层侦听 | —— | 需 `deep: true` |

```vue
<script setup>
import { ref, computed, watch } from 'vue';

const firstName = ref('张');
const lastName = ref('三');

// computed：派生数据，有缓存
const fullName = computed(() => firstName.value + lastName.value);

// watch：数据变化后做副作用
watch(fullName, (val, oldVal) => {
  console.log('名字变了', oldVal, '→', val);
  saveToServer(val);      // 异步副作用
}, { immediate: true });
</script>
```

**要点：**

- `computed` 是**纯计算**，不要在里做副作用（请求、改其他状态）。
- `watch` 适合**异步/开销大**的操作。
- `computed` 支持 `get`/`set` 实现可写计算属性。
- 排序、过滤、拼接展示用的数据 → `computed`；数据变化后发请求 → `watch`。

## 8. computed 与 methods 的区别？

| | `computed` | `methods` |
| --- | --- | --- |
| 缓存 | **有**（依赖不变不重新计算） | **无**，每次调用都执行 |
| 调用方式 | 当作属性使用 `{{ x }}` | 需调用 `{{ x() }}` |
| 适用 | 依赖响应式数据的派生值 | 事件处理、需要每次执行的逻辑 |

```vue
<script setup>
const list = ref([1, 2, 3]);
const total = computed(() => list.value.reduce((a, b) => a + b, 0)); // 缓存
const getTotal = () => list.value.reduce((a, b) => a + b, 0);        // 每次执行
</script>

<template>
  <p>{{ total }}</p>      <!-- 缓存 -->
  <p>{{ getTotal() }}</p> <!-- 每次渲染都执行 -->
</template>
```

**要点：** 只要依赖没变，`computed` 会**直接返回缓存值**，不像 `methods` 每次渲染都重新执行，因此模板中的派生展示优先用 `computed`。

## 9. class 与 style 的动态绑定

**class 绑定：**

```vue
<script setup>
import { ref, computed } from 'vue';
const isActive = ref(true);
const errorClass = ref('text-red');
const activeClass = ref('active');
const classObj = computed(() => ({
  active: isActive.value,
  'text-danger': hasError.value,
}));
</script>

<template>
  <!-- 对象语法 -->
  <div :class="{ active: isActive, 'text-danger': hasError }"></div>
  <!-- 数组语法 -->
  <div :class="[activeClass, errorClass]"></div>
  <!-- 混合 -->
  <div class="static" :class="[activeClass, { disabled: isDisabled }]"></div>
</template>
```

**style 绑定：**

```vue
<template>
  <div :style="{ color: activeColor, fontSize: size + 'px' }"></div>
  <div :style="[baseStyles, overridingStyles]"></div>
</template>
```

**要点：**

- 对象语法中 key 为 `true` 才生效，适合**条件类名**。
- 数组语法适合**多个类名组合**，可与静态 `class` 共存（会合并）。
- Vue 3 中 `:style` 支持**自动前缀**与 CSS 变量：

```vue
<div :style="{ '--theme-color': color }"></div>
```

## 10. v-model 的原理

**`v-model` 是语法糖**，本质是「**绑定 value + 监听 input 事件**」。

**原生元素上：**

```vue
<input v-model="msg" />
<!-- 等价于 -->
<input :value="msg" @input="msg = $event.target.value" />
```

**不同表单元素：**

| 元素 | 绑定属性 | 监听事件 |
| --- | --- | --- |
| `text` / `textarea` | `value` | `input` |
| `checkbox` | `checked` | `change` |
| `radio` | `checked` | `change` |
| `select` | `value` | `change` |

**修饰符：**

```vue
<input v-model.lazy="msg" />      <!-- change 时才同步 -->
<input v-model.number="age" />    <!-- 转数字 -->
<input v-model.trim="name" />     <!-- 去首尾空格 -->
```

**组件上（Vue 3）：**

```vue
<!-- 父组件 -->
<MyInput v-model="msg" />
<!-- 等价于 -->
<MyInput :modelValue="msg" @update:modelValue="msg = $event" />
```

```vue
<!-- 子组件 -->
<script setup>
defineProps(['modelValue']);
defineEmits(['update:modelValue']);
</script>
<template>
  <input :value="modelValue" @input="$emit('update:modelValue', $event.target.value)" />
</template>
```

**多 `v-model`（Vue 3）：**

```vue
<UserName v-model:first="first" v-model:last="last" />
```

**Vue 2 的差异：** 组件上默认是 `value` + `input`，可用 `model` 选项自定义；`.sync` 修饰符对应 Vue 3 的 `v-model:xxx`。

## 11. 事件处理与事件修饰符

```vue
<script setup>
const handleClick = (e) => console.log(e);
const handleWithArg = (id, e) => console.log(id, e);
</script>

<template>
  <button @click="handleClick">点击</button>
  <button @click="handleClick($event)">传事件对象</button>
  <button @click="handleWithArg(1, $event)">传参 + 事件</button>
</template>
```

**事件修饰符：**

| 修饰符 | 作用 |
| --- | --- |
| `.stop` | 阻止冒泡（`stopPropagation`） |
| `.prevent` | 阻止默认行为（`preventDefault`） |
| `.self` | 只有事件目标是自身才触发 |
| `.once` | 只触发一次 |
| `.capture` | 捕获阶段触发 |
| `.passive` | 提升滚动性能（不阻止默认） |
| `.native` | Vue 2 中监听组件根元素原生事件（Vue 3 已移除） |

```vue
<a @click.stop.prevent="doThis"></a>
<div @scroll.passive="onScroll"></div>
<input @keyup.enter="submit" />
<button @click.once="buy">立即购买</button>
<div @click.self="close">点击自身才关闭</div>
```

**按键修饰符：**

```vue
<input @keyup.enter="submit" @keyup.esc="cancel" />
<input @keyup.page-down="next" />
```

**要点：**

- 修饰符可**链式使用**，顺序会影响结果（如 `.self.stop` 与 `.stop.self`）。
- 事件名用 **kebab-case**（`@my-event`）。
- 修饰符本质是编译期包裹的 `withModifiers` 辅助函数。

## 12. 生命周期有哪些？

**Vue 3 生命周期（组合式 API 写法）：**

| 阶段 | 选项式 | 组合式（`setup` 中） | 说明 |
| --- | --- | --- | --- |
| 创建 | `beforeCreate` | —— | 实例初始化（Composition API 中已可忽略） |
| 创建 | `created` | —— | 实例创建完成，可访问数据（`setup` 本身即此时机） |
| 挂载 | `beforeMount` | `onBeforeMount` | 挂载前 |
| 挂载 | `mounted` | `onMounted` | 挂载完成，可访问 DOM、发起请求 |
| 更新 | `beforeUpdate` | `onBeforeUpdate` | 数据更新、DOM 更新前 |
| 更新 | `updated` | `onUpdated` | DOM 更新完成 |
| 卸载 | `beforeUnmount` | `onBeforeUnmount` | 卸载前（清理定时器/监听） |
| 卸载 | `unmounted` | `onUnmounted` | 卸载完成 |
| 缓存 | `activated` | `onActivated` | 被 `keep-alive` 缓存的组件激活 |
| 缓存 | `deactivated` | `onDeactivated` | 被缓存组件停用 |
| 错误 | `errorCaptured` | `onErrorCaptured` | 捕获后代组件错误 |

**Vue 2 命名差异：** `beforeDestroy` → `beforeUnmount`、`destroyed` → `unmounted`。

```vue
<script setup>
import { onMounted, onUnmounted } from 'vue';

let timer;
onMounted(() => {
  timer = setInterval(() => {}, 1000);  // 适合发起请求、操作 DOM
});
onUnmounted(() => {
  clearInterval(timer);                 // 必须清理，防止内存泄漏
});
</script>
```

**要点：**

- **发请求**通常在 `onMounted`（或 `setup` 中的 `await`，配合 `<Suspense>`）。
- **清理**定时器、事件监听、订阅必须在 `onBeforeUnmount` / `onUnmounted`。
- 子组件生命周期顺序：父 `beforeMount` → 子 `beforeMount` → 子 `mounted` → 父 `mounted`。

## 13. 组件通信有哪些方式？

| 场景 | 方式 |
| --- | --- |
| 父 → 子 | `props` |
| 子 → 父 | `emit` 自定义事件 |
| 双向 | `v-model` / `v-model:xxx` |
| 跨层级 | `provide` / `inject` |
| 任意组件 | **Pinia**（推荐）/ 事件总线（不推荐） |
| 访问实例 | `ref` + `defineExpose` |
| 内容分发 | `slot` |

```vue
<!-- 父 → 子 -->
<Child :title="title" />

<!-- 子 → 父 -->
<Child @update="handleUpdate" />

<!-- 跨层级 -->
<!-- 祖先 -->
<script setup>
provide('theme', readonly(theme));
</script>
<!-- 后代 -->
<script setup>
const theme = inject('theme', 'light'); // 第二个参数为默认值
</script>
```

**要点：**

- **props 单向数据流**：子组件不应直接修改 props（会警告），需要变更时 `emit` 让父改。
- 对象类型的 props 在**子组件内部修改**会污染父数据（Vue 只在开发环境警告），应避免。
- 复杂共享状态用 **Pinia**；`provide/inject` 适合主题、配置等**非响应式或低频**的依赖注入。
- Vue 3 移除了 `$on`/`$emit`/`$off` 实例方法，事件总线需用第三方库（如 `mitt`），但官方更推荐 Pinia。

## 14. slot 插槽

**① 默认插槽：**

```vue
<!-- 子组件 Card.vue -->
<template>
  <div class="card"><slot>默认内容</slot></div>
</template>

<!-- 父组件 -->
<Card>这里是内容</Card>
```

**② 具名插槽：**

```vue
<!-- 子组件 -->
<template>
  <header><slot name="header" /></header>
  <main><slot /></main>
  <footer><slot name="footer" /></footer>
</template>

<!-- 父组件 -->
<Card>
  <template #header><h1>标题</h1></template>
  <p>正文</p>
  <template #footer><button>确定</button></template>
</Card>
```

**③ 作用域插槽：** 子组件把数据「传回」给父组件的插槽内容。

```vue
<!-- 子组件：把 item 暴露给父 -->
<template>
  <ul>
    <li v-for="item in list" :key="item.id">
      <slot :item="item" :index="index">{{ item.name }}</slot>
    </li>
  </ul>
</template>

<!-- 父组件：接收子组件数据，自定义渲染 -->
<MyList :list="list">
  <template #default="{ item, index }">
    <span>{{ index }}. {{ item.name }}</span>
  </template>
</MyList>
```

**要点：**

- 插槽让组件更**灵活可组合**（如表格组件自定义列渲染）。
- 作用域插槽是「**子组件提供数据、父组件决定渲染**」的经典模式。
- Vue 3 中 `slot`/`slot-scope` 统一为 `v-slot`（简写 `#`）。

## 15. 动态组件与 keep-alive

**动态组件：** 用 `<component :is="...">` 动态切换组件。

```vue
<script setup>
import { shallowRef } from 'vue';
import TabA from './TabA.vue';
import TabB from './TabB.vue';

const current = shallowRef(TabA);   // 用 shallowRef 避免组件对象被深度代理
</script>

<template>
  <component :is="current" />
</template>
```

**`keep-alive`：** 缓存组件实例，避免重复销毁/重建，保留内部状态。

```vue
<template>
  <keep-alive :include="['TabA']" :max="10">
    <component :is="current" />
  </keep-alive>
</template>
```

| 属性 | 说明 |
| --- | --- |
| `include` | 只有匹配的组件会被缓存（字符串 / 正则 / 数组） |
| `exclude` | 匹配的组件不会被缓存 |
| `max` | 最多缓存数量（LRU 淘汰） |

**生命周期：** 被缓存的组件会多出 `onActivated` / `onDeactivated`。

```vue
<script setup>
import { onActivated, onDeactivated } from 'vue';
onActivated(() => console.log('进入'));
onDeactivated(() => console.log('离开'));
</script>
```

**要点：**

- `keep-alive` 会**保留组件状态**（如表单输入、滚动位置），但不会再次执行 `mounted`。
- 需要「每次进入都刷新数据」时，在 `onActivated` 中拉取，而非 `onMounted`。
- `<component :is>` 传组件对象时建议用 `shallowRef`/`markRaw`，避免不必要的代理开销。

## 16. nextTick 是什么？

**`nextTick`**：在**下一次 DOM 更新完成后**执行回调。

**为什么需要它？** Vue 的 DOM 更新是**异步批量**的：数据变化后不会立刻更新 DOM，而是把更新推入队列，在同一个事件循环的**微任务**中统一刷新。因此**修改数据后立即读取 DOM 会拿到旧值**。

```vue
<script setup>
import { ref, nextTick } from 'vue';
const msg = ref('old');
const pRef = ref(null);

async function update() {
  msg.value = 'new';
  console.log(pRef.value.textContent); // 'old'（DOM 还没更新）

  await nextTick();
  console.log(pRef.value.textContent); // 'new'

  // 或用回调写法
  nextTick(() => console.log(pRef.value.textContent));
}
</script>

<template>
  <p ref="pRef">{{ msg }}</p>
</template>
```

**要点：**

- `nextTick` 返回 **Promise**，可用 `await`。
- 底层基于**微任务**（`Promise.then` / `MutationObserver` 降级 `setTimeout`）。
- 常见场景：修改数据后**测量 DOM 尺寸、聚焦元素、初始化第三方库、滚动到指定位置**。
- Vue 3 中 `nextTick` 也可从 `vue` 直接导入使用（不再依赖 `this.$nextTick`）。
